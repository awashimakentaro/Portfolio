# トップページPC：最終確定

## 目的

プロフィール、作品、インターンシップ、コンタクトを1ページにまとめ、スクロールとキャラクターの動きを通して、自分の人物像・制作物・経験・連絡先を順番に伝える。

ページ全体を、黒背景と白文字を基本としたサイバー感のあるポートフォリオとして設計する。

## ページ全体の構成

```text
グローバルナビゲーション
        ↓
Profile / About Me
        ↓
本棚
  ├─ Works
  │   ├─ Agent
  │   ├─ Apps
  │   └─ Design
  └─ Internship
        ↓
Contact
```

## グローバルナビゲーション

### 基本構成

- 画面上部に固定する
- 黒背景・白文字を基本とする
- 左側にロゴまたは名前を配置する
- ロゴ・名前は「AK」を候補とする
- 右側にProfile、Works、Internship、Contactを配置する
- メニューはトップページ内の各セクションへスクロールする
- ロゴまたは「AK」からトップページ先頭へ戻る

### 表示と動き

- トップページ先頭では、Profile、Works、Internship、Contactのいずれも選択状態にしない
- ロゴまたは「AK」をトップページの現在地として扱う
- セクションへ移動した後は、対象メニューの文字色を変化させる
- ホバーされた文字だけが、横方向に弧を描くようにゆったり揺れる
- カーソルの背後や周辺には追従するイラストを表示しない
- 下線は必須にせず、文字色の変化を基本とする
- 動きを使えない環境では、文字色の変化だけで状態を示す

## Profile・About Me

### ファーストビュー

- 名前を左側に表示する
- キャラクターの上半身を中央に大きく表示する
- 希望職種を右側に表示する
- 希望職種は「ソフトウェアエンジニア」「UIデザイナー」とする
- キャラクターに軽い動きや視線の変化を加える

### About Me

- About Meの文章を左側に配置する
- キャラクターを右側に配置する
- 趣味、学校・専攻、これまでやってきたこと、興味のある分野、これから目指していることを紹介する
- 趣味の一つとして筋トレを扱い、キャラクターの動きで表現する
- キャラクターは中央から右側へ流れるように移動する

### 本棚への遷移

- プロフィールが終わると、キャラクターを小さくする
- キャラクターは本棚の右側へ移動する
- 本棚の案内役として「ここから選んでね」などの吹き出しを表示する
- 同じキャラクターを、本棚の案内役として表示する

## 本棚

### 基本構成

- 本棚は最初から表示する
- ワークスとインターンシップを1つの本棚にまとめる
- 本棚をワークスとインターンシップの区画に分ける
- ワークス内の分類はエージェント、アプリ、デザインとする
- 作品やインターンシップの経験を本として並べる
- 本棚の右側にミニマムキャラクターを配置する

### 本の選択から詳細表示まで

```text
本棚を表示
  ↓
本を選択
  ↓
本が手前に出て表紙を表示
  ↓
作品名・会社名・概要・リンクを確認
  ↓
「詳細を見る」を選択
  ↓
本が開き、ページがパラパラとめくれる
  ↓
詳細情報を表示
```

- 本棚の本にカーソルを合わせると、軽く揺れる、浮き上がるなどの反応を加える
- 表紙から詳細表示へ進む
- 詳細から戻ると表紙へ戻る
- 表紙から戻ると本棚へ戻る
- アニメーションが使えない場合は、本棚から詳細表示へ直接切り替える

### Works

作品カードまたは本の表紙には、以下を表示する。

- 作品名
- サムネイル
- アプリの概要を説明する短い一文
- デモリンク
- GitHubリンク

使用技術、制作期間、担当内容は作品カードには掲載しない。

作品本体を選択すると、表紙を経由して同じページ内の作品詳細を表示する。

### Internship

インターンシップごとに1冊の本として表示する。

本の表紙または詳細には、以下を表示する。

- 会社名
- インターンシップ名
- 在籍期間
- 担当内容

本を開くと、ページをめくるようにインターンシップの詳細を閲覧できる。

## 本棚の案内役キャラクター

- プロフィール内では常設せず、プロフィール終了後に本棚の右側へ移動したミニマムキャラクターとして表示する
- 本棚の分類や本の選び方を、短い吹き出しで案内する
- キャラクターをクリックしても、AI機能や会話パネルは開かない
- キャラクターがなくても、本棚の分類や本の選択が分かるようにする

## Contact

- ページ終盤に配置する
- キャラクターが「連絡してね」「気軽に話しかけてね」などと案内する
- Contactの見出しを表示する
- メールアドレスまたは問い合わせ先を通常のテキストやリンクで表示する
- 必要に応じてSNSや外部リンクを表示する
- 本棚の案内役と通常のContact導線を区別する

## 共通のアクセシビリティ・代替表示

- キャラクターが表示されなくても、各セクションの情報が読めるようにする
- 吹き出しだけに重要情報を依存させない
- アニメーション軽減時は、キャラクターの移動・揺れ・ページめくりを停止または簡略化する
- 本の演出がなくても、分類名、作品情報、インターンシップ情報を確認できるようにする
- デモ、GitHub、作品詳細、Contactの導線を区別して表示する

## 今後Figmaで調整する内容

- 各セクションの高さと余白
- キャラクターの正確なサイズと位置
- スクロールに対するキャラクターの移動量と速度
- 本棚の大きさ、棚の区切り、配置
- 本の表紙とカードのデザイン
- 本を開く演出とページめくりの速度
- 本棚案内用の吹き出しのサイズと位置
- Contactの具体的な連絡方法
