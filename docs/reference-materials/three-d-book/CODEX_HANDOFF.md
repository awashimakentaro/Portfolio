# Codex 引き継ぎ指示 — 3D Book Portfolio

## 目的
Next.js / React Three Fiber によるインタラクティブな3Dブック型ポートフォリオを実装し、Vercelにデプロイする。既存のスターターコードを起点に、実動作を確認して改修する。

## ここまでのユーザー決定事項（優先順位が高い）
1. 作品一覧は斜めを向いた本の横方向カルーセル。スワイプ・ドラッグや左右ボタンで別の本を選択できる。
2. 本を選択すると正面へ回転するだけ。**自動では開かない**。
3. 正面の表紙には各作品のサムネイル、タイトル、短い説明、クリック可能なDemo/GitHubリンクを置く。**View Detailsボタンは不要**。
4. 正面の表紙のリンク以外の領域をクリックすると本が開き、ページめくりに移る。
5. 本文は見出しとテキストの表示が主目的。文字選択・フォーム・本文リンクは当面不要。Canvasテクスチャでよい。
6. 本以外の背景をクリックすると本を閉じ、元の斜めカルーセル表示に戻る。
7. 表紙テンプレートは4種類で固定。各プロジェクトは `bookType` でそのうち1種類を選ぶ。追加時に3Dコードを変更する必要がないデータ駆動設計。
8. 表紙スタイルの参考はユーザーアップロード画像の中央にある、黒く質感のあるハードカバー本。ただし画像はデザインの参考であり、実際の3Dモデルのテクスチャや装飾は要制作。
9. ページめくりの参考: https://animated-book-slider-threejs.vercel.app/ および https://github.com/pakagronglb/animated-book-slider-threejs 、加えて https://github.com/Qbject/the-book-of-qbject 。参照実装のライセンスと帰属表示を確認すること。

## 現在の構成
- Next.js 15 / React 19 / TypeScript
- three / @react-three/fiber / @react-three/drei
- `src/data/projects.ts`: プロジェクトごとのデータ
- `src/data/bookTemplates.ts`: 4種類の表紙設定
- `src/components/book-gallery/BookGallery.tsx`: カルーセル、状態遷移、Canvas
- `src/components/book-gallery/Book3D.tsx`: 本の3D表示・クリック判定・ページめくり
- `src/lib/book/textures.ts`: 表紙・紙面のテクスチャ生成
- `public/thumbnails/`: 現時点ではプレースホルダー素材

## 作業タスク（必須）
1. `npm install`, `npm run typecheck`, `npm run build` を実施。エラー修正。
2. 3D描画のクリック領域を検証。Demo/GitHubを押してもページが開かず、他の表紙領域で開くこと。リンク未設定時の表示を見直す。
3. 本を開いたときに紙が本の左右両面へ正しく開き、裏面の文字が反転しないかを確認。ページ数可変に対応する。
4. 背景クリックで閉じてカルーセルに戻ること、カルーセル操作とページめくり操作が衝突しないことを検証。
5. 画面幅に応じて本のサイズ・カメラ・操作を調整。タッチデバイス対応、`prefers-reduced-motion`考慮。
6. プロジェクト・テンプレート情報をコードだけで追加できる構成を維持。
7. ビルドが通った後にVercelにデプロイし、公開URLを共有（デプロイには利用者のVercel権限設定が必要な場合がある）。

## 受け入れ条件
- 初期表示は正面本のカルーセル
- スライドで別の本に移動できる
- 本をクリック→閉じた表紙が少し前に来る
- Demo/GitHubリンクが別タブで開く
- 表紙余白クリック→開く
- 紙をめくるアニメーションで本文が表示される
- 背景クリック→閉じて斜め表示へ戻る
- 4種類の固定表紙をデータで割り当てられる
- `npm run typecheck` と `npm run build` が成功する
