# Portfolio v2.0 — 確定した内容

2026-11-06のヒアリングを反映。まずこの文書を読む。画面・操作の正本であり、旧資料と食い違う場合は本書を優先する。技術的な案はarchitecture.md、作業順はimplementation-plan.mdに分ける。

## 1. 作るもの【確定】

PC版のポートフォリオを先に完成させ、スマホ版はその後に調整する。Next.jsで制作し、Vercel公開を目指す。背景とキャラクターは採用済みの一体化したWebP映像で表示し、その上に文字・ナビ・3Dブックを重ねる。

`scroll-preview/`の映像素材・動きは基準として使い、フレームのつなぎ方や仕組みを参考にする。ただし、試作コードを本番の土台にするか、新しく実装するかは未確定。試作を再利用すること自体を完成条件にしない。比較用の試作と元素材は保存する。

## 2. 画面と映像【確定】

| 順番 | 表示内容 | 現行試作の映像ディレクトリ | 停止中の映像 |
|---|---|---|---|
| 1 | Profile | idle | loop-1 |
| 2 | About Me | one | loop-2 |
| 3 | History | two | loop-3 |
| 4 | Contact | three | loop-4 |

数字は画面の順番。会話の「2・3・4」とZIP名・ディレクトリ名を混同しない。Profileは冒頭のidleを含む。

- Profile・About Meは映像区間の開始から表示。Historyはキャラクターの退場とカメラ移動が終わり、停止地点のループ先頭フレームが実際に表示されてから文字と本を出す。本は約1.1秒でフェードしながら浮かび上がる。Contactは背景の先頭フレーム表示から約0.75秒後に文字を切り替える。待機に入ると前画面の文字を約0.65秒でフェードアウトし、その後は背景だけを見せる。ループ中も表示し続ける。待機中は前画面のコンテンツ操作を無効にし、ナビ操作は受け付ける。
- 通常の移動はホイール等をきっかけに区間を自動再生し、終点でループする。つなぎ方・正逆再生は試作を参考にする。再生中の追加シーン移動入力は無視する。
- 上スクロールで戻る場合は、現在の文字・本をフェードアウトし、背景の逆再生中は戻り先の内容を表示しない。戻り先のループ先頭が表示されてから内容を表示する。
- ナビは **Profile／About Me／History／Contact** の4項目。
- ロゴはAKのみで装飾の点を付けない。画面タイトル上の英語補助見出しと右下のスクロール案内は表示しない。画面タイトル自体に色と光の演出を付ける。
- ナビクリックでは途中の画面を順に再生せず、目的の画面へ直接移り、その画面の映像を最初から再生する。
- 映像の再生途中でもナビ操作を受け、現在の再生を中断して目的の画面へ移る。切替は唐突に見えないよう調整する。フェードの方式・時間は未確定。

## 3. Historyと本【確定】

カテゴリを選ぶと、そのカテゴリの作品・企業ごとの本だけがカルーセルに並ぶ。

| カテゴリ | 1冊ずつ表示する作品・企業 | 共通表紙（reference-materials/three-d-book/） |
|---|---|---|
| Apps | PFC Tracker、Campus Qiita、Kodo | App.png |
| Agents | Engineer Learning | Agent.png |
| Design | Awashima Portfolio | design.png |
| Internship | PR TIMES、HR Cloud | internship.png |

- 4枚の表紙はカテゴリ単位で共通利用し、作品ごとの画像・タイトル・Demo／GitHubリンクを重ねる。
- 左右の本をクリックすると中央へ移動し、少し前に出てリンクを操作できる。その表紙をクリックすると開く。Open bookボタンは不要。
- 一覧は横ドラッグ／スワイプとトラックパッドの横操作でも本を切り替えられる。正面向きで表示し、本全体を回す操作は設けない。横ドラッグは離した際に1冊だけ送り、一覧全体を引っ張って戻す動きは付けない。表紙単独の浮き・傾きは付けない。
- Appsは10冊形式（正式3作品＋確認用の架空Sample App 04〜10）に固定し、冊数比較・登場再生のテストボタンは表示しない。他カテゴリは既存の作品数を保つ。左右から入る本は画面外から連続して移動させ、表示中の端の本と同じ場所に生成しない。出現位置の境目は柔らかく馴染ませ、カテゴリ切替の落下は本全体が画面外の上に隠れた状態から始める。
- Demo／GitHubリンクのクリックでは本を開かない。未提供URLは捏造せず非表示にする。
- 本が中央にあるだけで、まだ開いていない場合は、ホイールでContactなどへ移動できる。
- Historyを離れて戻ったときは、選んでいたカテゴリと中央の本を覚えておく。本は閉じた表紙の状態で表示する。
- 本の中は黒い紙・白系の文字・左右に開く見開き。初期版の本文は文章のみ。
- 左右のページクリックと、外側のページ端からのドラッグで前後へ進む（追加ヒアリングで確定）。
- 最初の見開きの左ページ、または本の外側のクリックで閉じ、同じ本の表紙へ戻って本を選び直せる。Escで閉じる操作は補助として追加可。
- 読んでいる間も背景ループは継続する。本を開いている間、ホイールによる画面移動・本の切替は無効。
- 本を開いたら大きな見開きとして表示する。Historyのタイトル・カテゴリは半透明で背後へ退かせ、操作不可とする。「一覧に戻る」はページを一枚ずつ戻さず、表紙と全ページを同時に約0.32秒で閉じる。開閉・めくり途中からも閉じられ、古い操作の完了で閲覧状態に戻らない。見開きは従来より約2割拡大し、読書中の表示ボタンは下中央の「× 一覧に戻る」（本を閉じる操作）だけとし、ページは紙面のクリック／ドラッグと左右キーで送る。
- 本を開いた状態でナビを押した場合は、先に本を閉じ、閉じ終えてから目的の画面へ移動する。
