## 操作と期待結果

| 操作・状態 | 期待する表示・動作 |
|---|---|
| 初回表示 | Profileの映像を再生し、Profileの文字も表示 |
| 次・前の画面へ移動 | 対応する映像と文字を表示し、到着後は同じ文字とループを維持 |
| ナビクリック | 目的の画面へ直接切替え、その区間の映像を再生 |
| 区間再生中にナビクリック | 現在の再生を中断し、なめらかに目的画面へ切替えて、その映像を再生 |
| カテゴリ変更 | 対象カテゴリの本だけを表示。先頭の本を中央へ（基準資料） |
| 左右の本をクリック | 中央へ移動して少し前に出る。自動では開かない |
| 中央の表紙をクリック | 本が開く。別の選択ボタンやOpen bookボタンは設けない |
| 表紙のDemo／GitHubリンク | 外部リンクへ。本は開かない |
| 本が閉じて中央にある | ホイールでHistoryからContactなどへ移動可能 |
| Historyを離れて戻る | 前に選んだカテゴリと中央の本を、閉じた表紙で表示 |
| 本を開いている | 背景ループを継続。ホイールによる移動・本の切替は無効 |
| 左／右ページをクリック | 前／次の見開きへ。最初の左ページは本を閉じる |
| ページ外側の端からドラッグ | 紙が指に追従して湾曲し、離す位置に応じて確定または元へ戻る |
| 本の外側をクリック | 閉じて、同じ本の表紙とカルーセル操作へ戻る |
| 本を開いてナビクリック | 本を閉じ終えてから目的の画面へ直接移り、映像を再生 |

## 実装時に調整すること【提案】

- フェード時間、文字の入退場、正逆移動中の切替を実画面で合わせる。表示開始はProfile・About Meでは区間開始、Historyではループ先頭の表示後、Contactでは背景開始の約0.75秒後に合わせる。
- 最後の右ページではそれ以上進めず、ページ境界を越えない。
- 0冊・1冊のカテゴリでも配置を保ち、存在しない本を操作対象にしない。
- 本の開閉・ページめくり中の重複操作を抑止する。
- モバイルはPC完成後。WebGL非対応時のHTML作品一覧、動きの低減設定は基準資料の方針を踏まえて実装設計する。

正確なフォント・余白・カメラ値・モーション値は未確定。Figmaのフレームは参照可能だが、各スタイル値の取得・実画面照合はこれから行う。

## 映像と文字・本の演出（実装済みの確認版）

FrameEngineが実際に描いたフレームから区間進捗とループ進捗を通知する。再生のフレーム選択や速度は変えず、UIはCSS変数、本は参照経由で同じ進捗を読む。毎フレームのReact state更新は行わない。

- 文字：画面の表示開始で見出しの立ち上がりと光の通過、本文・カテゴリの時間差表示。光と位置の一部は映像進捗に追従する。
- 本：区間の冒頭で奥から現れ、区間進捗に合わせて姿勢が収まる。輪郭を照らす光、細かな光粒、背景になじませる光を加える。
- ホバー：表紙単独の傾き・浮きは廃止。本体は正面表示とし、回転操作は設けない。
- 読書中：登場移動を収めて光粒と光の変化を弱める。ページの進捗・座標は演出から独立させる。
- 動きを減らす設定：登場・光沢・粒子・文字アニメーションを停止し、開閉・ページ操作は利用可能にする。

同期対象は映像の再生タイミング。画像内のカメラや照明を自動推定する実装ではない。本番ビルド、PCの既存主要操作、進捗の更新、動きを減らす設定を実行確認済み。演出追加後のFPS測定・モバイル実機確認は未実施。

## UIの整理と読書表示

AKの装飾点、画面タイトル上の英語補助見出し、右下のスクロール案内を削除。Profileは暖色、About Meは淡い青銀、Historyは落ち着いた金、Contactは真珠色のタイトルにする。タイトルの光沢は継続する。

一覧の本は正面向きで、回転機能は設けない。表紙だけを浮かせるホバー演出も付けない。横ドラッグ／スワイプは離した時に一定距離を超えた場合だけ次・前へ1冊送る。ドラッグ中の一覧全体の引っ張り・引き戻しは付けない。横ホイールは縦スクロールによる画面移動と分離する。

開くと同じCanvas内で本を拡大し、Historyタイトル・カテゴリは透明度8%とぼかしで背後に置く。ページ送りボタンと一覧操作は表示せず、下中央に既存のカテゴリ・矢印ボタンと揃えた、暗い半透明背景・淡い枠線・白系文字の「× 一覧に戻る」を置き、クリック領域は48px以上の高さを確保する。見開きはHTML領域の高さ94%を上限として従来より拡大し、閉じる操作の余白を残す。表示領域はナビを除くHistory全体を使い、めくり途中の高さも収める。1440×900／1280×720で一覧・読書・めくり途中を確認した。

About MeからHistoryへ進むときは、背景が動き始めたらAbout Meを約0.65秒でフェードアウトする。カメラ移動中は背景だけを表示し、Historyのループ先頭で文字・カテゴリ・本をフェードインする。ヘッダーは表示を保つ。実ブラウザーで途中の透明度低下・完全非表示・ループ後の登場を確認済み。

逆方向の通常スクロールは、行き先の文字を区間開始で出さず、逆再生完了後のループ先頭で表示する。History→About Me、About Me→Profile、Contact→Historyをブラウザーで確認。移動中は現在の内容が約0.65秒で消え、背景だけが見える。Profile→About Meの順方向は区間開始のまま。

## Appsの10冊表示

Appsは10冊固定。正式3作品＋架空のSample App 04〜10を使用する。架空の本文は実績ではないと明記し、URLは登録しない。他カテゴリは既存の冊数を保つ。冊数切替・登場再生の確認ボタンは表示しない。

中央＋左右2冊ずつの最大5冊が見える配置とし、残りは循環操作で選ぶ。画面外にも前後の本を配置し、共有の移動進捗で全冊の位置・大きさを計算する。端の本の位置に新しい本を生成しない。3D描画領域はHTMLの余白より外側へ広げ、左右端を透明グラデーションで馴染ませる。本文閲覧中は端のマスクを解除する。本の最終位置・大きさは元のHTML領域を基準に保つ。連打時も移動中の本が描画範囲から消えないよう、現在位置と目的位置の両方を含める。

初回登場は本全体が画面上端より外に隠れる位置から、時間差をつけて落下・反発し、着地に短い光粒を加える。カテゴリ切替ではStageの生成時に一度だけ開始し、画面上部で静止した本を見せてから再始動しない。落下対象は登場開始時に見える本に限定し、横送りで画面外から入る本は再落下させない。読書中は落下を即座に収める。動きを減らす設定では落下・反発・光粒と横移動の補間を停止する。

以前の3／5／10冊比較は終了し、ユーザー指定により10冊形式を採用。今回の実ブラウザー確認では、1440×900／1280×720の表示、10→1／1→10の循環、12回連続送り、左右ドラッグで1冊ずつ移動、横ホイール、1冊・2冊カテゴリ、サンプルの開閉・ページ送り・閲覧中ホイール無効、動きを減らす設定を確認した。冊数切替・回転・登場再生の確認ボタンは0件。FPS・GPUメモリ計測は未実施。

## 文章・Contactの最終調整

Profileの英語名をAwashima Kentaroに変更。希望職種ラベルを18pxに拡大。Profileの見出しと名前・英語名はPCで36px下げ、希望職種は位置を保つ。Profile見出しは合字を無効にし、字間を詰めない。About Meは最新指定の5段落と「目標」を採用し、背景が明るい位置にも暗幕を敷く。Contactは指定の2行に差し替え、封筒／GitHubのアイコン、行動ラベル、宛先・アカウントを一枚のリンクにまとめた。

1440×900／1280×720で文章・配置・本の拡大・閉じる操作を確認。Gmailリンクは新しいタブで宛先を保持したGoogleログイン画面まで確認した。ログイン済み環境の作成画面と送信は未検証。GitHubは指定プロフィールへの遷移を確認した。

一覧復帰時は表紙と全ページを同時に約320msで閉じ、逐次ページ送りを行わない。途中の開閉・ページ操作は操作IDを更新して中断し、古い非同期完了で状態を書き戻さない。一度開いた本の周囲には落下演出を再適用せず、照明の復帰も補間する。非選択本は閲覧中も非表示で保持し、復帰時の形状・テクスチャ再生成を避ける。非表示中は表紙の入力ハンドラーも外す。SpringRef.startが返す全Promiseの完了を待ってから一覧へ復帰する。

Historyの入場時は、その場でCanvasを生成せず、最初の映像ループ到達時またはHistoryへの移動開始時に非表示で準備する。表紙のデコード・透過範囲走査をカテゴリごとに共有し、各作品のタイトルテクスチャは個別に解放する。表紙が揃った後、画面外の表紙も含めてGPU転送をフレームごとに分散し、シェーダー準備と隠れた描画を通してから、History到達に合わせてフェードと落下を開始する。非表示中はdemand描画とし、再入場ではCanvasを再生成しない。カテゴリ変更時は準備状態をリセットし、非同期完了のカテゴリIDを照合する。GPU事前準備の例外時には通常描画へ戻し、透明のまま待ち続けない。

今回のPC本番ブラウザー（1440×900）の初回History表示後1.5秒では、50ms超のLong Taskと30ms超のrAF間隔は観測されなかった。変更前の同期間には417ms／661msのLong Task、最大約950msのrAF間隔があった。計測環境・一試行の結果であり、全端末での性能保証ではない。1440×900／1280×720で全カテゴリ・再入場・ページ送り・一覧復帰を確認した。

初回のローディングは暗い背景と、ゆっくり動く軌道・実際の取得率に連動する金色の進捗リングのみを表示する。説明文・名前・ロゴ・フッター・数字は表示しない。読み上げ用の進捗と失敗時の再試行アイコンは保持する。素材準備中はナビや画面操作を表示しない。完了後の画面移動には「映像を読み込んでいます」の途中表示を挟まない。初回待機は増えるが、圧縮状態の素材をすべて端末内へ保持して以後の通信待ちを避ける。

事前読み込みの本番ビルド検証では968件の素材取得を確認し、完了後に/frames/への通信をすべて拒否してもHistory・Contact・逆方向の再生と本の開閉／ページ送りが成功した（再生中の素材HTTP要求0件）。503応答を模擬した失敗表示と再試行復帰、動きを減らす設定で代表4枚のみの取得もブラウザーで確認した。全端末でのデコード性能を保証するものではない。

ローディング完了時はリングが満ちた状態を約0.48秒保ち、光を強める。その後ローダーが約1秒でフェードアウトし、Profileの背景と文字が約1.2秒でフェードインする。背景の冒頭フレームは完了表示中に一時停止し、フェード開始時に再開する。入力は登場完了まで無効。動きを減らす設定では装飾アニメーションと完了待機を省略し、準備後すぐに表示する。
