# 実装計画と完了条件

## 現状

PCの背景映像・4画面・ナビ・HistoryのR3F本は実装済み。背景原本はassets/frames、試作はarchive/scroll-preview、本の制作原本はbooks。現行構成はarchitecture.mdを参照する。仮本文とStudio下書きは正式公開内容として確定していない。

## アーキテクチャ修正

1. Book障害時のHTML退避と公開0冊表示。完了条件：Book以外のナビ・Contactを使え、読書中障害でも入力ロックが解除される。
2. 公開契約をpublication.tsへ独立。完了条件：下書きの不正構文・未作成設定が本番生成へ影響せず、公開設定の不正は検出する。既存7冊の本文・順序を保持する。
3. 公開表紙URLを描画へ接続。完了条件：カテゴリ固定ではなく指定URLが取得・使用される。
4. 素材取得に本文受信までのタイムアウト。完了条件：停止した通信を再試行し、再失敗では画面から再試行できる。
5. 静止ページの骨・境界再計算を省略。完了条件：クリックとドラッグ、閉じてナビ移動の既存操作が保たれる。

実行結果はreviews/architecture-review-2026-11-07.mdへ記録する。未実行の検証を成功としない。

## 続く制作

Portfolioに明示ページ・画像・リンク・目次を接続した。次は本文と見た目の本人確認→残りの紙面表現の整備→他作品・インターンへ展開する。接続完了は本文・画像・リンク・ページ順・めくり・開閉を実画面で照合すること。長い本の負荷は代表原稿で計測してから準備範囲や遅延生成を判断する。

## 共通の回帰条件

- 前進時Profile・About Meは区間開始から、Historyは前進映像の進捗42.5%から、Contactは約0.75秒後に表示。逆方向は移動先到着待機。移動元内容はフェードアウトする。
- 通常再生中も新しいホイール操作で次へ進める。慣性による1操作では1移動だけとし、ナビは目的区間へ直接移動する。
- 閉じた本では背景移動可能。開閉・閲覧・復帰中は無効、ナビは閉じてから実行。背景ループ継続。
- 左右の本の選択、中央表紙クリック、クリックとドラッグのページ送り、一覧へ戻る操作ができる。
- 公開0冊とWebGL障害は正常な代替表示へ復帰する。
- 制作メモ・下書きを公開出力に混ぜず、readyだけで公開しない。
