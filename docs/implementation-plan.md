## PC版の完了条件

- Profile／About Me／History／Contactが決めた映像とループに対応し、区間開始から文字が見える。
- ナビは目的の区間へ直接移り、その映像を再生する。通常移動の再生中は追加ホイールで区間を飛ばさない。
- 区間再生中のナビは再生を中断して目的画面へ切り替わる。切替の見た目をPC実画面で確認する。
- 4カテゴリ7冊が正しく絞り込まれ、指定のカテゴリ共通表紙と作品情報が表示される。
- 左右の本は中央へ移動して前に出る。中央表紙クリックで開き、リンククリックでは開かない。
- 閉じた本が中央にある間はホイールで画面移動でき、開閉・閲覧・復帰中はホイールを無効にする。
- 閲覧中も背景ループが続き、左右ページクリック、最初の左ページで閉じる、本の外側で閉じる操作ができる。
- 閲覧中のナビは閉じ終えてから移動する。解除後に古いホイール入力を再生しない。
- 実行したテストだけを報告する。仮本文・画像・リンクの状態を明示する。

正確な速度・余白・カメラは実画面で調整する。素材容量・依存バージョンは確認前に推測しない。scroll-previewと元画像は保存する。
