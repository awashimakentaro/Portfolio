# 09 公開・ユーザーテスト

## 目的

実際の環境で、ユーザーが情報を見つけ、操作し、演出を含む体験を無理なく利用できるか確認する。

## 実施する作業

- Webポートフォリオを公開する
- 主要導線、表示速度、音声、3D、アニメーションの動作を確認する
- 音声OFF、アニメーション軽減、3D非対応環境でもテストする
- ユーザーインタビュー、アンケート、行動観察などを行う
- 演出が理解を助けたか、邪魔したかを確認する

## 成果物

- 公開版Webサイト
- ユーザーテスト計画・記録
- 回答データ・観察記録
- 改善候補一覧

## 次工程へ進む目安

観察結果と回答が整理され、問題の内容・発生条件・優先度を説明できる状態。
