# 11 ケーススタディ作成

## 目的

完成画面だけでなく、課題、判断、設計、検証、改善をUI/UX制作のケーススタディとして説明できる形にまとめる。

## 実施する作業

- 各工程の目的、作業、成果物、判断理由を整理する
- 3D・モーション・音声・インタラクションを採用した理由と検証結果を記録する
- 演出がユーザー体験に与えた効果と、制約・代替手段を示す
- 企画から改善までの変更履歴を整理する
- 未決定事項や今後の改善も明示する

## 成果物

- UI/UXポートフォリオのケーススタディ
- 制作過程の要約
- 設計資料、検証結果、改善履歴への導線

## 次工程へ進む目安

第三者が、何を作ったかだけでなく、なぜその設計にし、どう検証し、何を改善したかを追える状態。
