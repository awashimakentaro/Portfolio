# 手順メモ

## 繰り返し使うワークフロー

1. 題材の利用者、課題、成功条件を一文ずつ書く。
2. 代表タスクを一つ決め、行動を時系列に並べる。
3. AIを使う場合は、目的・利用者・タスク・状態・制約をまとめて渡し、2〜3案のフローまたは低忠実度画面を出す。
4. 採用する案を選び、Figmaで画面と遷移を整える。繰り返す要素はコンポーネントにする。
5. 代表タスクをクリック試作で試してもらい、迷い・不足情報・例外状態をメモする。
6. 修正後に、ビジュアルデザインと細部の調整へ進む。

## チェックリスト

- [ ] 各画面に主目的が一つある
- [ ] 最重要の行動が見つけやすい
- [ ] 情報の優先順位が視線の流れに合っている
- [ ] 次の画面と戻る先が分かる
- [ ] 入力エラー、空状態、完了状態を考えた
- [ ] AIの案を鵜呑みにせず、利用者タスクで確認した
