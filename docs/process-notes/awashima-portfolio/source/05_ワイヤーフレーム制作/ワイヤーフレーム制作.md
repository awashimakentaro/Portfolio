# 05 ワイヤーフレーム制作

## 目的

ユーザーが必要な情報を見つけ、主要な目的を達成できるように、画面構成と情報配置を決める。装飾や演出の完成形は後回しにする。

## 実施する作業

- 04のユーザーフローとインタラクション仕様を画面に落とし込む
- 情報の優先順位、ナビゲーション、作品への導線を配置する
- キャラクターや3D演出を置く候補領域を確保する
- 演出がなくても理解・操作できる基本レイアウトを作る
- PC・スマートフォンでの主要画面を確認する

## 成果物

- 低忠実度ワイヤーフレーム
- 画面一覧と画面間の対応
- 主要導線の確認メモ

## 次工程へ進む目安

主要情報、主要導線、作品詳細への遷移、演出を除いた基本操作が説明できる状態。
