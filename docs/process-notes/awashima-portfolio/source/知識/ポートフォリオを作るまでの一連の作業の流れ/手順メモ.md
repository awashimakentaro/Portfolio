# 手順メモ

1. 企画・要件定義を行う。
2. ユーザー調査と課題整理を行う。
3. 機能と情報を設計する。
4. ユーザーフローを設計する。
5. Figmaでワイヤーフレームを作る。
6. UI・ビジュアルデザインを作る。
7. プロトタイプを作り、検証する。
8. Webアプリを実装する。
9. 公開してユーザーテストを行う。
10. データや調査結果を分析し、改善する。
11. 制作過程をケーススタディとしてまとめる。

実際の制作では、テストや分析の結果に応じて、企画・設計・ワイヤーフレーム・UIデザインなどの前工程へ戻る。3D・モーション・サウンドは、目的と必要性を確認しながら小さく検証し、ユーザー体験を損なう場合は縮小・代替する。
