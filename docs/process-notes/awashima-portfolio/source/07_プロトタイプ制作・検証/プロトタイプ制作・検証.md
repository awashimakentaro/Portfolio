# 07 プロトタイプ制作・検証

## 目的

実装前に、ユーザーが情報を探し、操作し、演出を受け取る流れが自然かを確認する。

## 実施する作業

- 画面遷移と主要操作をFigmaなどで再現する
- クリック、ホバー、スクロール、フォーカスの反応を検証する
- キャラクターの案内、モーション、音声、効果音の仮表現を試す
- 演出あり・演出を減らした状態・演出なしの体験を比較する
- 小規模な技術検証で、3D表示やアニメーションの実現可能性を確認する
- ユーザーが迷う場所、遅く感じる場所、情報を見落とす場所を記録する

## 成果物

- 操作可能なプロトタイプ
- インタラクション検証結果
- 小規模な3D・モーション・音声技術検証の記録
- 修正点と次工程への引き継ぎ

## 次工程へ進む目安

主要導線と情報理解に問題がなく、実装する演出の優先順位、代替表示、検証項目が決まっている状態。
