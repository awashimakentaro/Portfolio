# 06 UI・ビジュアルデザイン制作

## 目的

ワイヤーフレームをもとに、情報の見つけやすさとポートフォリオの世界観を両立した視覚表現を設計する。

## 実施する作業

- 配色、フォント、余白、レイアウト、コンポーネントを設計する
- デザインシステムとコンポーネントの状態を作る
- 3Dキャラクター、背景、エフェクトのビジュアル案を検討する
- BlenderやSplineなどの3D素材を、仮素材を含めてFigmaに配置する
- モーションや音声表現の参考資料と、視覚上の方向性を整理する
- 音声OFF、アニメーション軽減、3D非対応時の代替表示を設計する

この工程で3Dモデルや演出を完成させる必要はない。未確定の外見や動きを確定事項として扱わず、案・仮素材・検討事項として記録する。

## 成果物

- FigmaによるUIデザイン
- デザインシステム
- ムードボード
- 3Dキャラクターのビジュアル案
- モーション・音声表現の参考資料

## 次工程へ進む目安

主要画面の視覚表現とコンポーネント状態が揃い、演出を含めた検証対象と、演出なしでも成立する基本画面が説明できる状態。
