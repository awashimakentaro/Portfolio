# プロフィール：最終確定

## 目的

キャラクターの動きとプロフィール情報を組み合わせて、自分がどんな人で、何を目指しているのかを自然に伝える。

## ページ全体の流れ

```text
ファーストビュー
  名前：左側
  キャラクター：中央
  希望職種：右側
        ↓ スクロール
About Me
  文章：左側
  キャラクター：右側で筋トレなどの動き
        ↓ プロフィール終了
本棚セクション
  キャラクターが小さくなり、右側へ移動
  本棚の案内役を担当
```

## 掲載情報

### ファーストビュー

- 名前を左側に表示する
- キャラクターの上半身を中央に大きく表示する
- 希望職種を右側に表示する
- 希望職種は「ソフトウェアエンジニア」「UIデザイナー」とする

### About Me

- About Meの文章を左側に配置する
- キャラクターを右側に配置する
- 趣味、学校・専攻、これまでやってきたこと、興味のある分野、これから目指していることを紹介する
- 趣味の一つとして筋トレを扱い、キャラクターの動きで表現する

### プロフィール終了後のキャラクター

- プロフィールが終わると、キャラクターを小さくして右側へ移動させる
- 本棚セクションでは、本棚の案内役として表示する
- 本の選び方や分類を吹き出しで案内する
- 同じキャラクターを本棚の案内役として表示する
- 「ここから選んでね」など、本の選び方を伝える短い吹き出しを表示する

## ビジュアルデザイン

- グローバルナビゲーションと同じく、黒背景・白文字を基本とする
- キャラクターをプロフィールページの視覚的な中心として扱う
- 文章部分は十分な余白を取り、キャラクターの動きと競合させない
- セクションごとにキャラクターの位置とサイズを変える
- 本棚の案内役となるミニマムキャラクターは、右側に配置する

## キャラクター・演出

- ファーストビューではキャラクターを中央に表示する
- About Meへスクロールすると、キャラクターが中央から右側へ流れるように移動する
- About Meでは右側で筋トレなどの趣味に関する動きを見せる
- プロフィール終了後は、キャラクターが小さくなって右側へ移動する
- 本棚セクションでは、右側で本棚の使い方を案内する
- ミニマムキャラクターは本棚の案内役として使用する
- キャラクターの視線追従は、必要に応じてカーソルの方向を見る程度にする

## インタラクション

- スクロールに合わせてキャラクターの位置・サイズ・役割を変化させる
- キャラクターの移動は急に切り替えず、流れるように見せる
- 本棚セクションでミニマムキャラクターをクリックしても、AI機能や会話画面は開かない

## アクセシビリティ・代替表示

- キャラクターが表示されなくても、名前、希望職種、About Meの内容が読めるようにする
- キャラクターの吹き出しだけに重要情報を依存させない
- アニメーション軽減時は、キャラクターの移動を停止または簡略化する
- キャラクターがなくても、本棚の分類や本の選択を通常のテキストやボタンで操作できるようにする

## 方針として確定した内容

- ファーストビューは「名前：左、キャラクター：中央、希望職種：右」とする
- About Meは「文章：左、キャラクター：右」とする
- キャラクターをプロフィールページ内で継続的に表示する
- About Meでは筋トレなどの趣味をキャラクターの動きで表現する
- プロフィール終了後、キャラクターを小さくして本棚の右側へ移動させる
- 本棚ではキャラクターを案内役として使用する
- ミニマムキャラクターは本棚側の案内役として表示する

## 今後Figmaで調整する内容

- 名前、キャラクター、希望職種の正確なサイズと余白
- キャラクターの表示サイズ
- About Meの文章量と左右比率
- 筋トレアニメーションの動き、速度、頻度
- 本棚へ移動した後のキャラクターのサイズと位置
- 本棚案内用の吹き出しの文言
- 本棚案内用の吹き出しのサイズ、位置、文言
- スクロールに対するキャラクターの移動量と速度
- 視線追従を使う範囲
