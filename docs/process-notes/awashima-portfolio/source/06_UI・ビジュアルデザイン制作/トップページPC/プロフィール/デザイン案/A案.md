# プロフィール デザイン案A

## 案の概要

プロフィールページ内でキャラクターを継続的に表示し、スクロールに合わせてキャラクターの位置・大きさ・役割を変化させる構成。

キャラクターがページ内を流れるように移動しながら、名前、希望職種、About Me、あわしまAIを順番に紹介する。

## 全体の流れ

```text
ファーストビュー
  キャラクターが中央にいる
  名前・希望職種を表示
        ↓ スクロール
About Me
  キャラクターが右側へ流れるように移動
  趣味・学校・これまでの活動を紹介
        ↓ スクロール
あわしまAI
  キャラクターが小さくなり、右側へ移動
  あわしまAIの紹介と会話への導線を表示
```

## ファーストビュー

- キャラクターの上半身を画面中央に大きく表示する
- キャラクターの上部または周囲に名前を表示する
- 希望職種として「ソフトウェアエンジニア」「UIUXデザイナー」を表示する
- キャラクターは静止画ではなく、軽い動きや視線の変化を持たせる
- 画面を開いた時点で、プロフィールページであることが分かる見出しを置く

## About Meへの遷移

- About Meへスクロールすると、キャラクターが中央から右側へ流れるように移動する
- 移動後は、キャラクターを右側に継続表示する
- About Meの文章は左側に配置する
- キャラクターがページの内容を案内しているように見せる
- 遷移は急に切り替えず、ページのスクロールと連動した動きにする

## About Meの内容

- 趣味
- 学校・専攻
- これまでやってきたこと
- 興味のある分野
- これから目指していること

## あわしまAIへの遷移

- About Meからさらにスクロールすると、キャラクターが流れるように移動する
- キャラクターは小さくなり、画面右端から顔だけを覗かせる状態に変化する
- 右端のミニキャラクターは、スクロール後も同じ位置に留まる
- ミニキャラクターは本文に少し重なってもよいが、表示面積を小さく保つ
- ミニキャラクターをクリックすると、右側からキャラクターがひょこっと飛び出す
- 展開後は「知りたいことあった？」などの言葉で会話を始める
- 趣味などの質問に対して、プロフィール情報を会話形式で答えられるようにする
- 会話を閉じると、右端から顔だけを覗かせる状態へ戻る

## あわしまAIの表示状態

### 通常時：覗き見状態

- 画面右端に顔だけを表示する
- 右側の同じ位置に固定する
- 本文に少し重なってもよい
- 小さな動きやまばたきなどで存在を示す
- クリックできることが分かる反応を加える

### クリック後：会話状態

- 右側からキャラクターが飛び出すように展開する
- 「知りたいことあった？」などの問いかけを表示する
- 会話内容や質問入力のための領域を表示する
- 閉じる操作で覗き見状態へ戻す
- 会話パネルが重要な本文を隠す場合は、閉じる操作を常に見える位置に置く

## キャラクターの動き

- キャラクターはプロフィールページ内で常に何らかの形で表示する
- スクロールに合わせて、位置・大きさ・向きを変化させる
- 画面遷移のように急に消すのではなく、流れるように移動させる
- 動きはページ内容の理解を助ける範囲に抑える
- キャラクターの視線追従を使う場合は、カーソルの方向を自然に見る程度にする
- あわしまAIの通常時は右端から顔だけを覗かせる
- あわしまAIをクリックしたときだけ、会話のために大きく展開する

## ビジュアルの方向性

- グローバルナビゲーションと同じく、黒背景・白文字を基本とする
- キャラクターを画面上の視覚的な中心として扱う
- 文章部分は十分な余白を取り、キャラクターの動きと競合させない
- セクションごとにキャラクターの位置を変えることで、ページの流れを作る

## アクセシビリティ・代替表示

- キャラクターが表示されなくても、名前、希望職種、About Me、あわしまAIの内容が読めるようにする
- アニメーション軽減時は、キャラクターの移動を停止し、位置を切り替えるだけにする
- キャラクターの吹き出しや会話だけに重要情報を依存させない
- あわしまAIへの導線は、通常のテキストやボタンでも認識できるようにする
- あわしまAIを閉じる操作を分かりやすく表示する
- 会話状態を閉じても、プロフィール本文の閲覧に戻れるようにする

## 現時点での確定内容

- キャラクターをプロフィールページ内で継続的に表示する
- ファーストビューではキャラクターを中央に置く
- 名前と希望職種をファーストビューに表示する
- About Meではキャラクターを右側へ移動させる
- About Meでは趣味、学校、これまでの活動などを紹介する
- あわしまAIではキャラクターを小さくし、右端から顔を覗かせる
- クリックするとキャラクターが飛び出して会話を開始する
- 会話を閉じると、右端から顔を覗かせる状態へ戻る
- AIの名称は「あわしまAI」とする

## これから決めること

- キャラクターの正確な表示サイズ
- ファーストビューでの名前と希望職種の位置
- About Meでの文章とキャラクターの左右比率
- あわしまAIの覗き見状態と会話状態の正確なサイズ
- スクロールに対する移動量と速度
- キャラクターの視線追従を使う範囲
- あわしまAIの会話開始ボタンや入力方法
- 会話パネルの閉じる操作と、本文との重なり方
