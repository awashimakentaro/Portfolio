# トップページPC：最終仕様 v2.0

## 1. 目的

プロフィール、制作物、インターンシップ経験、コンタクトを1ページにまとめ、スクロールとキャラクターの動きを通して、自分の人物像・制作物・経験・連絡先を順番に伝える。

ページ全体は、黒背景と白文字を基本とした、サイバー感と高級感のあるインタラクティブなポートフォリオとして設計する。

特にWorksセクションには、3Dブックを使用した回転式カルーセルを採用する。

ユーザーがジャンルを選び、3Dの本を回転させながら作品を探し、表紙から実際のデモや詳細情報にアクセスできる体験を目指す。

---

## 2. ページ全体の構成

```
グローバルナビゲーション
  ├─ AK（ページ先頭）
  ├─ Profile
  ├─ Works
  └─ Contact

        ↓

1. Profile
  ├─ First View
  └─ About Me

        ↓

2. Works
  └─ 3D Book Gallery
      ├─ Apps
      ├─ Agents
      ├─ Design
      └─ Internship

        ↓

3. Contact
```

### 基本方針

- トップページは縦スクロールの1ページ構成とする。
    
- Profile、Works、Contactを3つの主要セクションとする。
    
- Internshipは独立セクションを設けず、Works内のジャンルとして扱う。
    
- 各ジャンルでは、3Dブックを使って作品・経験を表示する。
    
- セクション内の情報閲覧は、原則としてトップページ内で完結させる。
    
- キャラクターの動きやスクロール連動アニメーションで、セクション間の体験をつなぐ。

## 3. グローバルナビゲーション

### 3.1 基本構成

- 画面上部に固定表示する。
    
- 黒背景・白文字を基本とする。
    
- 左側にロゴ「AK」を配置する。
    
- 右側にProfile、Works、Contactを配置する。
    
- 各項目をクリックすると対象セクションへスムーズにスクロールする。
    
- AKをクリックするとページ先頭へ戻る。
    

### 3.2 選択状態

- ページ先頭ではProfile、Works、Contactのどれも選択状態にしない。
    
- AKをページ先頭の現在地として扱う。
    
- 各セクションに移動すると、対応するナビゲーションの文字色が変化する。
    
- Internshipジャンルの閲覧中も、Worksを選択状態にする。
    
- ナビゲーションの選択状態はスクロール位置と同期する。
    

### 3.3 ホバーアニメーション

- ホバーした文字だけが横方向に弧を描くようにゆったり揺れる。
    
- カーソル追従イラストは設置しない。
    
- 下線は必須とせず、文字色の変化を基本とする。
    
- アニメーション軽減環境では、動きを停止して文字色の変化だけを使用する。

## 4. Profile / About Me

### 4.1 ファーストビュー

ページにアクセスした際、最初に表示される領域。

#### レイアウト

- 画面左側：名前
    
- 画面中央：キャラクターの全身
    
- 画面右側：希望職種
    

希望職種は以下の2つとする。

- ソフトウェアエンジニア
    
- UIUXデザイナー
    

#### 表示・アニメーション

- キャラクターを画面中央に大きく表示する。
    
- キャラクターに軽い動きや視線の変化を加える。
    
- 黒背景と白文字を基調にする。
    
- キャラクターが視覚的な主役になるよう、周囲の装飾は控えめにする。
    

### 4.2 About Me

#### レイアウト

- 左側：自己紹介文
    
- 右側：キャラクター
    

#### 掲載情報

- 趣味
    
- 学校・専攻
    
- これまでの活動や経験
    
- 興味のある技術・分野
    
- 今後目指していること
    

趣味の一つとして筋トレを扱い、キャラクターのアニメーションでも表現する。

#### スクロール演出

- スクロールに合わせて、キャラクターが中央から右側へ移動する。
    
- テキストの表示タイミングとキャラクターの動きを調整する。
    
- 過度に高速な移動や、不自然な位置の切り替わりを避ける。
    

### 4.3 Worksへの遷移

- Profileの終了に合わせてキャラクターを小さくする。
    
- キャラクターはWorksの右側へ移動する。
    
- Worksに到達すると、本の案内役になる。
    
- 「ここから作品を選んでね」などの短い吹き出しを表示する。
    
- ファーストビューと同じキャラクターを継続して使用する。

## 5. Works — 3D Book Gallery

### 5.1 基本コンセプト

Worksでは、制作物とインターンシップ経験を本として表現する。

従来の固定された本棚ではなく、3D空間で本が円形の軌道を回る「回転式ブックカルーセル」を採用する。

中央に選択中の本を大きく表示し、左右には前後の本を小さく半透明で表示する。

ユーザーが左右へスライドすると、本が円形の軌道を移動し、次の本が中央に現れる。

本の表紙は基本的にカメラの正面を向く。

### 5.2 画面構成

```
                  WORKS

    Apps   Agents   Design   Internship
                  ↑
              ジャンル選択


 [前の本]       [選択中の本]       [次の本]
   小               大               小
  半透明           不透明           半透明
   奥               手前             奥


             ←   01 / 05   →

```

### 5.3 ジャンル分類

作品と経験を以下の4種類に分類する。

#### Apps

Webアプリケーション、モバイルアプリケーションなど。

#### Agents

AIエージェント、自動化ツール、AIを活用したシステムなど。

#### Design

UI/UXデザイン、Webデザイン、プロトタイプ、デザインケーススタディなど。

#### Internship

インターンシップ、実務プロジェクト、企業での開発経験など。

### 5.4 ジャンル選択

- 画面上部に4つのジャンル選択ボタンを配置する。
    
- 選択肢はApps、Agents、Design、Internshipとする。
    
- 選択中のジャンルは文字色やアクセントカラーで強調する。
    
- ジャンルを選択すると、該当ジャンルに所属する本だけが表示される。
    
- ジャンル変更後は、そのジャンルの先頭の本を中央に表示する。
    
- 切り替え時はフェードや移動を組み合わせた自然な演出を使用する。
    
- 登録数が0冊または1冊の場合でもレイアウトが破綻しないようにする。
    

### 5.5 4種類の表紙テーマ

本の色はジャンルと対応させる。

暫定配色は以下とする。

|ジャンル|アクセントカラー|
|---|---|
|Apps|シアン|
|Agents|パープル|
|Design|アンバー|
|Internship|グリーン|

すべての表紙は、黒い高級感のあるハードカバーを共通ベースとする。

ジャンルごとに装飾線・縁・アクセントカラーなどを変更する。

本の3D構造、基本レイアウト、ページめくり処理は共通化する。

## 6. 3D回転式カルーセル

### 6.1 中央の本

- 中央に選択中の本を1冊大きく表示する。
    
- 表紙は正面を向く。
    
- 透明度を100%にする。
    
- タイトル、説明文、サムネイルが十分に読み取れる大きさとする。
    
- 中央の本をほかの本より手前に配置する。
    
- 表紙の四隅が画面からはみ出さないようにする。
    
- 画面サイズに合わせて自動的に表示倍率を調整する。
    

### 6.2 左右の本

- 中央の本の左右に、前後の本を表示する。
    
- 中央より小さくする。
    
- 半透明で表示する。
    
- 中央から離れるほど、サイズと透明度を下げる。
    
- 奥行き方向へ移動させ、円形軌道上にあるように見せる。
    
- 外側の本は自然にフェードアウトさせる。
    
- 表紙は基本的に正面を向いたままとする。
    

### 6.3 カルーセルアニメーション

ユーザーが左へスライドした場合：

1. 中央の本が左方向へ移動する。
    
2. 移動中の本が奥へ下がる。
    
3. 本が縮小し、半透明になる。
    
4. 右側の本が手前へ移動する。
    
5. 新しい本が中央で拡大する。
    
6. 透明度100%になり、新しい本が選択状態になる。
    

反対方向では逆の動作を行う。

移動は滑らかに補間し、瞬間的な切り替えは避ける。

### 6.4 操作方法

- マウスドラッグによる左右スライド
    
- トラックパッドによる横スクロール
    
- スマートフォンでのスワイプ
    
- 左右の本のクリック
    
- 前後の矢印ボタン
    
- 現在の本番号と総冊数の表示
    
- 最後の本から最初の本へ循環するループ
    

マウスホイール操作を導入する場合は、通常の縦スクロールを妨げないようにする。

### 6.5 パフォーマンス

- 中央の本を高品質で表示する。
    
- 左右の本は必要に応じて描画処理を軽量化する。
    
- 画面外の本は描画を省略する。
    
- テクスチャは適切にキャッシュする。
    
- ジャンル切り替え時に不要な3Dリソースを解放する。
    
- 操作中も滑らかなアニメーションを維持する。

## 7. 本の表紙

### 7.1 共通デザイン

提供された黒い本の参考画像を基準とする。

- 黒いハードカバー
    
- マットな革または布張りの質感
    
- 細かい傷や擦れ
    
- 自然な角の丸み
    
- 厚みのある背表紙
    
- 装飾用の細い線
    
- 星や軌道を連想させる装飾
    
- 控えめなアクセントカラー
    
- 自然な陰影と立体感
    

表紙はすべての本で共通レイアウトを使用する。

### 7.2 Apps・Agents・Designの表紙

表示する情報：

1. プロジェクトのサムネイル
    
2. 作品タイトル
    
3. 短い説明文
    
4. Demoリンク
    
5. GitHubリンク
    
6. Open bookボタン
    

使用技術、制作期間、担当内容は表紙に表示せず、本を開いた後の詳細ページに掲載する。

### 7.3 Internshipの表紙

表示する情報：

- 会社名
    
- インターンシップ名または役割
    
- 在籍期間
    
- 担当内容の短い要約
    
- 会社ロゴまたは画像
    
- Open bookボタン
    

実務上の機密情報や、公開許可のない成果物は掲載しない。

### 7.4 表紙の操作

- Demoリンクをクリックすると外部デモを開く。
    
- GitHubリンクをクリックするとリポジトリを開く。
    
- URLのないリンクは表示しない。
    
- Open bookをクリックすると本を開く。
    
- 表紙の余白をクリックしても本を開ける。
    
- 外部リンクのクリックが開閉操作と競合しないようにする。

## 8. 本の内部ページ

### 8.1 デザイン

本を開いた後は、黒い紙を使った詳細ページを表示する。

- 背景：チャコールブラック
    
- 文字：オフホワイト
    
- 見出し：明るい白
    
- 本文：淡いグレー
    
- 細かな紙の質感
    
- 自然な中央の湾曲
    
- ページ端の厚みと重なり
    
- 紙の動きに応じた影
    
- 適切な余白と読みやすい文字組み
    

### 8.2 作品の内部ページ

基本的な情報構成：

- Overview：作品概要
    
- Background：制作背景と課題
    
- Approach：設計・解決方法
    
- Technology：使用技術
    
- Development：実装内容と工夫
    
- Outcome：成果と学び
    

プロジェクトに合わせて項目やページ数は変更可能とする。

### 8.3 Internshipの内部ページ

基本的な情報構成：

- Overview：企業・業務概要
    
- Role：担当した役割
    
- Projects：実際に取り組んだ業務
    
- Challenges：課題と解決方法
    
- Outcome：成果・学び
    

公開可能な内容だけを掲載する。

### 8.4 ページめくり

- 紙の端をクリックまたはドラッグしてめくれる。
    
- ページは自然に湾曲しながら移動する。
    
- 文字や画像は紙の変形に追従する。
    
- 表裏のページを自然に描画する。
    
- ページめくり中も黒い紙の質感を維持する。
    
- 不自然な貫通やちらつきを防止する。
    
- ページ数は作品ごとに可変とする。

## 9. 本の状態遷移

```
Worksへスクロール
      ↓
ジャンル選択
      ↓
3Dカルーセル表示
      ↓
左右スライドで本を選択
      ↓
中央の本の表紙を確認
      │
      ├─ Demo → デモサイト
      │
      ├─ GitHub → GitHub
      │
      └─ Open book
              ↓
          本が開く
              ↓
         ページめくり
              ↓
          本を閉じる
              ↓
         中央の表紙へ
              ↓
      カルーセル操作を再開
```

### 操作ルール

- カルーセル表示時は本の切り替えが可能。
    
- 本が開いている間はカルーセルの操作を停止する。
    
- 開いた本の外側をクリックすると、本を閉じる。
    
- 本を閉じると、選択していた本の表紙に戻る。
    
- カルーセル操作を再開する。
    
- ジャンルを切り替えると、そのジャンルの本が表示される。
    
- アニメーション中の誤操作を防ぐ。

## 10. Worksの案内役キャラクター

### 10.1 配置

- Profile終了後、同じキャラクターが小さくなってWorksの右側へ移動する。
    
- ミニマムなキャラクターとして表示する。
    
- 中央の本や操作UIに重ならない位置とする。
    
- 浮遊や視線変更などの控えめな動きを加える。
    

### 10.2 吹き出し

操作状況に応じて、短い吹き出しを表示する。

例：

- 「ここから作品を選んでね」
    
- 「アプリの作品はこちら！」
    
- 「AIエージェントを紹介するよ」
    
- 「デザイン作品も見てね」
    
- 「インターンでの経験はこちら」
    
- 「本を開いて詳しく見てみてね」
    

### 10.3 制約

- キャラクターをクリックしてもAIチャットは開かない。
    
- キャラクターに会話パネルを設置しない。
    
- キャラクターがいなくても操作が理解できるようにする。
    
- 吹き出しだけに重要な説明を依存させない。

## 11. Contact

### 11.1 基本構成

- トップページの最後に配置する。
    
- Contactの見出しを表示する。
    
- キャラクターが連絡を促す。
    
- メールアドレスまたは問い合わせ先をリンクで表示する。
    
- 必要に応じてGitHubやSNSなどの外部リンクを表示する。
    

### 11.2 演出

- WorksからContactへスクロールすると、キャラクターも移動する。
    
- Contactではキャラクターを少し大きく表示してもよい。
    
- 「気軽に話しかけてね」「連絡してね」などの吹き出しを表示する。
    
- Contactのリンクは通常のHTML要素として操作できるようにする。

## 12. アクセシビリティ・代替表示

- キャラクターがなくても内容を読めるようにする。
    
- 吹き出しだけに重要情報を依存させない。
    
- アニメーション軽減設定では、キャラクターの動きや本の回転・ページめくりを停止または簡略化する。
    
- WebGLを利用できない場合は、通常の作品カード一覧を表示する。
    
- ジャンル選択や本の切り替えはキーボードでも操作できるようにする。
    
- Demo、GitHub、Open book、Contactのリンクを区別する。
    
- フォーカス位置を視覚的に確認できるようにする。
    
- モバイルでも中央の本と操作UIが画面内に収まるようにする。
    
- 通常の縦スクロールを不必要に妨げない。

## 13. 技術構成

既存の3Dブック実装を活用し、以下の技術を中心に構成する。

|技術|用途|
|---|---|
|Next.js|アプリケーション|
|TypeScript|型安全なデータ管理|
|React Three Fiber|3Dシーン|
|Three.js|本の3Dモデルとマテリアル|
|Drei|3D描画補助|
|React Spring / GSAP|移動・回転アニメーション|
|SkinnedMesh|ページめくりの湾曲|
|Canvas Texture|表紙・本文の描画|
|Tailwind CSS|3D以外のUI|
|GSAP ScrollTrigger等|スクロール連動演出|

### データ構造

```
type ProjectCategory =
  | "apps"
  | "agents"
  | "design"
  | "internships";

interface BookProject {
  id: string;
  category: ProjectCategory;
  title: string;
  description: string;
  thumbnail?: string;
  demoUrl?: string;
  githubUrl?: string;
  pages: {
    heading: string;
    body: string;
  }[];
}
```

### 実装方針

- 1つの共通3Dブックコンポーネントを使用する。
    
- 本の外観と作品データを分離する。
    
- ジャンルごとに表紙テーマを切り替える。
    
- 作品データの追加だけで新しい本を生成できる。
    
- 表紙のサムネイル・文字・リンクは動的に描画する。
    
- 本の開閉・ページめくり・カルーセル処理は共通化する。
    
- 不要な再レンダリングとテクスチャ生成を抑える。

## 15. 最終的なユーザー体験

1. ページにアクセスし、名前・希望職種・キャラクターを見る。
    
2. スクロールするとAbout Meが表示され、人物像や興味を知る。
    
3. キャラクターが小さくなり、Worksの案内役になる。
    
4. WorksでApps・Agents・Design・Internshipからジャンルを選ぶ。
    
5. 選択したジャンルの本が3D回転式カルーセルに表示される。
    
6. 左右にスライドしながら作品を選ぶ。
    
7. 中央の本の表紙からサムネイル・説明・リンクを確認する。
    
8. DemoやGitHubを開くか、本を開いて詳細を読む。
    
9. 本を閉じ、次の作品を探す。
    
10. Contactへスクロールし、連絡先を確認する。
