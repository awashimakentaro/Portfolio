# コンタクト デザイン案A

## 案の概要

プロフィール、ワークス、インターンシップを見た後に、キャラクターが連絡先へ案内するシンプルなセクション。
情報を増やしすぎず、連絡方法がすぐ分かることを優先する。

## 掲載内容

- Contactの見出し
- キャラクターからの短い案内
- メールアドレスまたは問い合わせ先
- 必要に応じてSNSや外部リンク

## キャラクターの役割

- セクションの最後にキャラクターを表示する
- 「連絡してね」「気軽に話しかけてね」などの吹き出しを表示する
- キャラクターの表情や小さな動きで、堅くなりすぎない印象を作る
- 連絡先そのものは吹き出しだけに依存させず、通常のテキストやリンクでも表示する

## ビジュアルデザイン

- 黒背景・白文字を基本とする
- プロフィールや本棚と同じキャラクターデザインを使用する
- 連絡先への導線を大きく、分かりやすく表示する
- あわしまAIとの会話導線と、通常のContact導線を混同しないようにする

## インタラクション

- メールアドレスや問い合わせボタンをクリックできるようにする
- ホバー時は文字色やキャラクターの小さな反応を加える
- 連絡先をクリックした後の動作は、メールソフト起動または問い合わせページへの移動とする

## アクセシビリティ・代替表示

- キャラクターが表示されなくても、連絡先とリンクが確認できるようにする
- 吹き出しがなくても、Contactの目的が分かる見出しを表示する
- アニメーション軽減時はキャラクターを静止させる

## 現時点での確定内容

- Contactはページ終盤に配置する
- キャラクターが連絡先へ案内する
- 吹き出しで「連絡してね」という雰囲気を作る
- 連絡先は通常のテキストやリンクでも表示する

## これから決めること

- メールアドレスを直接表示するか、問い合わせボタンにするか
- SNSや外部リンクを掲載するか
- キャラクターの表情や動き
- 吹き出しの具体的な文言
