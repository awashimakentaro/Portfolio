# コンタクト：最終確定

## 目的

ポートフォリオを見た人が、連絡先や問い合わせ方法を迷わず確認できるようにする。キャラクターを最後の案内役として配置し、気軽に連絡できる印象を作る。

## 掲載情報

- Contactの見出し
- メールアドレスまたは問い合わせ先
- 必要に応じてSNSや外部リンク
- キャラクターからの短い案内

## ビジュアルデザイン

- 黒背景・白文字を基本とする
- プロフィールや本棚と同じキャラクターデザインを使用する
- 連絡先への導線を見つけやすく表示する
- 本棚の案内役と通常のContact導線を区別する

## 入力・送信導線

## インタラクション

- メールアドレスや問い合わせボタンをクリックできるようにする
- ホバー時は文字色やキャラクターの小さな反応を加える
- 連絡先のクリック後は、メールソフト起動または問い合わせページへ移動する

## アクセシビリティ・代替表示

- キャラクターが表示されなくても、連絡先とリンクを確認できるようにする
- 吹き出しがなくても、Contactの目的が分かる見出しを表示する
- アニメーション軽減時はキャラクターを静止させる

## 確定内容

- Contactはページ終盤に配置する
- キャラクターが連絡先へ案内する
- 吹き出しで「連絡してね」という雰囲気を作る
- 連絡先は通常のテキストやリンクでも表示する

## 今後Figmaで調整する内容

- メールアドレスを直接表示するか、問い合わせボタンにするか
- SNSや外部リンクを掲載するか
- キャラクターの表情や動き
- 吹き出しの具体的な文言
