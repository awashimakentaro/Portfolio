# グローバルナビゲーション デザイン案A

## 案の概要

画面上部に固定する、横並び型のグローバルナビゲーション。
ページ上部では背景を透過または半透明にし、スクロール後は背景色・ぼかし・境界線などを追加して、ナビゲーションの視認性を高める。

情報の見つけやすさと操作の安定性を優先しつつ、3Dキャラクターや背景の世界観を補助的に取り入れる。

黒い背景に白を基本とした文字やUIを組み合わせ、必要に応じて小さなアクセントカラーを加える。全体としては、黒と白のコントラストを活かしながら、サイバー感と少し不思議な世界観を感じられる方向を目指す。

## 基本構成

```text
[ロゴまたは名前]                         Profile  Works  Internship  Contact
```

- 左側にロゴまたは名前を配置する
- 左側のロゴ・名前は現時点では「AK」を候補とする
- 右側に以下のメニューを配置する
  - Profile
  - Works
  - Internship
  - Contact
- ロゴまたは名前からトップページへ戻れるようにする
- Profile、Works、Internship、Contactは、トップページ内の各セクションへスクロールする
- PC画面では横並びで表示する
- ナビゲーションの高さは太くなりすぎない、適度なサイズにする
- 文字サイズは一般的なWebサイトで読みやすい範囲から検討する

## スマートフォン表示

- スマートフォンでは横並びメニューをハンバーガーメニューに切り替える
- 画面上部にハンバーガーボタンを配置する
- ボタンを押すと、Profile、Works、Internship、Contactを一覧表示する
- メニュー展開中は、閉じるボタンまたは同じハンバーガーボタンで閉じられるようにする
- 開閉状態はアイコンの変化だけでなく、`aria-expanded`などでも伝わるようにする

## 表示状態

### ページ上部

- 黒背景を基本とする
- 必要に応じて透明または半透明のレイヤーを重ねる
- 3D背景やキャラクターを隠しすぎない
- 文字は白を基本とし、背景に対して十分なコントラストを確保する

### スクロール後

- 画面上部に固定する
- 黒を基調とした半透明の背景、ぼかし、薄い境界線などを追加する
- 背景と文字が重なっても、メニューを読み取れる状態にする
- 必要に応じてナビゲーションの高さを少し小さくする

### 現在地

- トップページの先頭では、Profile、Works、Internship、Contactのいずれも選択状態にしない
- ロゴまたは「AK」をトップページの現在地として扱う
- 各セクションへスクロールした後は、必要に応じて対象メニューの文字色を変化させる

### ホバー時

- 文字色を変化させる
- 下線は必須にせず、文字色の変化を基本とする
- ホバーされたメニューの文字だけに揺れの反応を加える
- ホバー中は、横方向に弧を描くように、ゆったりと揺れ続ける
- 左右に単純に振るのではなく、少し円弧を描くことで浮遊感を出す
- 反応はカーソルを合わせている間だけ発生させ、通常時は静止させる
- 揺れはゆっくりで控えめにし、別のメニューを選びやすい状態を保つ
- キャラクターを連動させる場合は、視線移動や表情変化など控えめな演出にする

### カーソル周辺の扱い

- カーソルの背後や周辺には、追従するイラストやキャラクターを表示しない
- カーソル自体は通常の操作に必要な表示として扱う
- ホバー時の反応は、カーソルではなく対象となるメニュー項目やナビゲーション内の演出に限定する
- メニュー名と現在地は、文字色と対象項目の動きで認識できるようにする

### 動きの方向性

- UI全体の印象として、整然としすぎない活発さや多動的な雰囲気を表現する
- ただし、操作対象が分からなくなるほど大きく動かさない
- 動きの強さは、通常時よりホバー時にだけ高める
- ホバー中の揺れは、短い一回の反応ではなく、カーソルを外すまで継続する
- アニメーション軽減設定が有効な場合や動きを使えない環境では、揺れを停止し、文字色の変化だけにする

### クリック時

- 対象ページまたは対象セクションへ移動する
- 移動後に現在地の表示を更新する
- スクロールアニメーションを使用する場合も、移動先が分からなくならない速度にする

## キャラクター・3D表現の扱い

- 添付のキャラクター案をビジュアルの出発点とする
- グローバルナビゲーションでは、キャラクター全体の3Dモデルを主役として使用しない
- 必要に応じて、キャラクターの下半身や一部のイラスト要素をナビゲーション周辺の演出として使用する
- メニューの文字情報をキャラクターだけに依存させない
- キャラクターが表示されない場合でも、通常の文字リンクとして操作できるようにする
- プロフィール画面では、キャラクターの上半身を大きく配置する案を別途検討する
- プロフィール画面のキャラクターは、カーソルの方向に目を動かす視線追従を候補とする
- 3Dモデルの詳細な外見や動きは未確定の検討事項として扱う

## アクセシビリティ・代替表示

- アニメーション軽減時は、移動や反応のアニメーションを停止または簡略化する
- 3D表示に対応していない環境では、静止画像または通常のナビゲーションに切り替える
- 文字と背景のコントラストを確保する

## 現時点での確定内容

- A案をグローバルナビゲーションの第一候補とする
- 上部固定型を基本とする
- ロゴまたは名前を左側に配置する
- Profile、Works、Internship、Contactを右側に配置する
- スマートフォンではハンバーガーメニューに切り替える
- ページ上部とスクロール後でナビゲーションの背景表現を変える
- トップページの先頭ではメニューを選択状態にせず、ロゴまたは「AK」を現在地として扱う
- セクション移動後は、必要に応じて対象メニューの文字色を変化させる
- ホバー時に横方向へ弧を描く、ゆったりとした継続的な揺れを加える
- 動きを使えない環境では、文字色の変化だけで状態を示す
- キャラクターや3D表現は補助的に使用する

## これから決めること

- ロゴまたは名前の具体的なデザイン
- 「AK」をロゴとして採用するかどうか
- ナビゲーションの高さ、余白、文字サイズ
- サイバー感と不思議な世界観に合うフォント
- 黒背景・白文字を基本とした文字色とアクセントカラー
- 背景の透明度、ぼかし、境界線
- セクション移動後の現在地表示を文字色でどう表現するか
- ホバー時の文字の揺れ方
- ホバー対象となるメニュー項目や演出の具体的な形と位置
- キャラクターの下半身をナビゲーション演出に使うかどうか
- プロフィール画面で使う上半身3Dモデルの仕様
- 視線追従の範囲と動き方
- スマートフォンのハンバーガーメニューの展開方法
- ホバー時の揺れの振幅、周期、弧の大きさ
