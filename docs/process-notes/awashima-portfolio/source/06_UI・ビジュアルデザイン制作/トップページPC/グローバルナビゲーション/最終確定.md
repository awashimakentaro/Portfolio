# グローバルナビゲーション：最終確定

## 目的

トップページ内の各セクションへ迷わず移動できるようにしながら、ポートフォリオ全体の黒を基調としたサイバー感・不思議な世界観を補助する。

## 掲載項目

- 左側：ロゴまたは名前。現時点では「AK」を候補とする
- 右側：Profile、Works、Internship、Contact
- 各メニューはトップページ内の対応するセクションへスクロールする
- ロゴまたは「AK」からトップページ先頭へ戻る

## ビジュアルデザイン

- 黒背景を基本とする
- 文字は白を基本とする
- 必要に応じて小さなアクセントカラーを加える
- ナビゲーションは画面上部に固定する
- ナビゲーションの高さは太すぎない、適度なサイズにする
- 文字サイズは一般的なWebサイトで読みやすい範囲にする
- 3Dキャラクターをグローバルナビゲーションの主役にはしない
- カーソルの背後や周辺に追従するイラストやキャラクターは表示しない

## インタラクション

- トップページ先頭では、Profile、Works、Internship、Contactのいずれも選択状態にしない
- ロゴまたは「AK」をトップページの現在地として扱う
- 各セクションへ移動した後は、必要に応じて対象メニューの文字色を変化させる
- ホバーされた文字だけに反応を加える
- ホバー中は、横方向に弧を描くようにゆったりと揺れ続ける
- 揺れはカーソルを外すと停止する
- 下線は必須にせず、文字色の変化を基本とする
- クリック時は対象セクションへスクロールする
- スクロールアニメーションを使用する場合も、移動先が分かる速度にする

## アクセシビリティ・代替表示

- アニメーション軽減時や動きを使えない環境では、揺れを停止する
- 動きを停止した場合は、文字色の変化だけで状態を示す
- キャラクターや3D演出が表示されない場合でも、通常の文字リンクとして操作できるようにする
- 文字と背景のコントラストを確保する
- スマートフォン表示ではハンバーガーメニューへ切り替える方針とする。詳細は別途検討する

## キャラクター・3D表現

- 添付のキャラクター案を、ポートフォリオ全体のビジュアルの出発点とする
- グローバルナビゲーションでは、キャラクターの下半身や一部のイラスト要素を補助演出として使う可能性がある
- プロフィール画面では、キャラクターの上半身を大きく配置する案を別途検討する
- プロフィール画面のキャラクターは、カーソルの方向に目を動かす視線追従を候補とする

## 方針として確定した内容

- グローバルナビゲーションはA案の上部固定型とする
- 黒背景・白文字を基本とする
- メニューはProfile、Works、Internship、Contactとする
- メニューはトップページ内の各セクションへスクロールする
- 先頭ではメニューを選択状態にせず、ロゴまたは「AK」を現在地として扱う
- ホバーされた文字だけが、横方向に弧を描くようにゆったり揺れる
- カーソルの背後には何も表示しない
- 下線は必須とせず、文字色の変化を基本とする
- キーボード用のフォーカス表示は、今回のビジュアル仕様には含めない

## 今後Figmaで調整する内容

- 「AK」ロゴの具体的な形
- フォント
- 文字サイズ、ナビゲーションの高さ、余白
- 黒背景の色味と白文字の明るさ
- アクセントカラー
- ホバー時の揺れの強さ、周期、弧の大きさ
- スクロール後の背景の透明度、ぼかし、境界線
- スマートフォンのハンバーガーメニューの詳細
