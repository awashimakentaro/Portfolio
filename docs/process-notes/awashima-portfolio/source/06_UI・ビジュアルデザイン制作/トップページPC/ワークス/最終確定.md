# ワークス：最終確定

## 目的

作品とインターンシップの経験を、最初から表示されている1つの本棚にまとめて整理する。本棚の区切りから本を選び、表紙を確認してから本を開くことで詳細情報や外部リンクへつなげる。

## 掲載情報

- 作品名
- 作品サムネイルまたは本の表紙
- 作品がどのようなアプリなのかを説明する短い一文
- デモリンク
- GitHubリンク

作品カードには、使用技術、制作期間、担当内容を掲載しない。

## ビジュアルデザイン

- グローバルナビゲーションやプロフィールと同じ世界観を共有する
- 黒背景・白文字を基本とする
- 本棚を作品と経験を整理・保管するUIとして表現する
- 作品は本の表紙またはカードとして見せる
- 本棚の右側に案内役のミニマムキャラクターを配置する
- ミニマムキャラクターは吹き出しで本棚の見方を案内する

## 本棚・作品構成

- ワークスとインターンシップを1つの本棚にまとめる
- 本棚をワークスとインターンシップに分ける
- ワークス内に「エージェント」「アプリ」「デザイン」の区切りを設ける
- 作品は本またはカードとして本棚に並べる
- 作品本体をクリックすると手前に出て、まず表紙を表示する
- 表紙にはサムネイル、作品名、デモリンク、GitHubリンクを表示する
- 表紙の「詳細を見る」を選択すると本を開く
- 本が開いた後、ページをめくるように作品詳細を表示する
- 同じ分類内に複数の作品がある場合は、横方向へスライドして切り替える

## インタラクション

- 本棚の本にカーソルを合わせると、軽く揺れる、浮き上がるなどの反応を加える
- クリックすると本が手前に出て、表紙を表示する
- 表紙の「詳細を見る」を選択すると本が開く
- ページがパラパラとめくれる演出の後、作品詳細を表示する
- デモリンクから実際のアプリへ移動する
- GitHubリンクからソースコードへ移動する
- 詳細から戻ると表紙へ戻り、表紙から戻ると本棚の一覧へ戻る
- ミニマムキャラクターは「ここから選んでね」などの吹き出しで本棚を案内する

## アクセシビリティ・代替表示

- 本を開く演出が表示されなくても、表紙と作品情報を確認できるようにする
- アニメーション軽減時は、本棚から詳細表示へ直接切り替える
- 作品詳細、デモ、GitHubへの導線をそれぞれ区別する

## 確定内容

- ワークスとインターンシップを1つの本棚にまとめる
- 本棚は最初から表示する
- 本棚をワークスとインターンシップに分ける
- ワークスの分類はエージェント、アプリ、デザインとする
- 作品は本またはカードとして表示する
- 本を選択すると表紙を表示する
- 表紙から「詳細を見る」を選択すると本を開く
- 本のページめくり後に、同じページ内で作品詳細を表示する
- 同じ分類内の作品は横方向へスライドして閲覧する
- カードには作品名、サムネイル、短い説明、デモリンク、GitHubリンクを掲載する
- 使用技術、制作期間、担当内容はカードには掲載しない

## 今後Figmaで調整する内容

- 本棚の大きさ、棚の区切り、配置
- 本の表紙とカードの見た目
- 本を開く演出と切り替え速度
- 一度に表示するカードの枚数
- カードの大きさと横幅
- 左右の矢印やページインジケーターの有無
- カードとリンクの具体的なデザイン
- ホバー時のカードの動き
