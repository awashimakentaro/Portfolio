# インターンシップ：最終確定

## 目的

ワークスとインターンシップの経験を、最初から表示されている1つの本棚にまとめる。本棚のインターンシップ区画から本を選び、表紙を確認してから本を開くことで、経験を読み進められるようにする。

## 掲載情報

- 会社名
- インターンシップ名
- 在籍期間
- 担当内容
- インターンシップで経験したこと
- 学んだこと
- 必要に応じて詳細情報へのリンク

## ビジュアルデザイン

- ワークスと同じ本棚の中に配置する
- 本棚の区切りとして「インターンシップ」を表示する
- インターンシップごとに1冊の本として扱う
- 黒背景・白文字を基本とする
- 本の表紙に会社名やインターンシップ名を表示する
- 会社ごとに表紙の色や装飾を変えることを検討する
- 本棚の右側に配置するミニマムキャラクターと案内吹き出しを共有する

## 本棚・本の構成

- ワークスの「エージェント」「アプリ」「デザイン」と同じ本棚に収納する
- インターンシップの区切りに複数の本を並べる
- 本を選択すると、まず表紙を表示する
- 表紙には会社名、インターンシップ名、概要、必要なリンクを表示する
- 表紙の「詳細を見る」を選択すると本を開く
- 本が開いた後、ページをめくるように詳細情報を表示する
- 複数の本がある場合は横方向へスライドして閲覧する

## インタラクション

- 本にカーソルを合わせると、軽く揺れる、浮き上がるなどの反応を加える
- クリックすると本が手前に出て、表紙を表示する
- 表紙の「詳細を見る」を選択すると本が開く
- ページをめくるような動きで、経験の内容を順番に閲覧できるようにする
- 詳細から戻ると表紙へ戻り、表紙から戻ると本棚の一覧へ戻る

## アクセシビリティ・代替表示

- 本を開く演出がなくても、表紙と会社名やインターンシップ情報を確認できるようにする
- アニメーション軽減時は、本棚から詳細表示へ直接切り替える
- ページをめくる動きがなくても、通常のボタンや矢印で内容を切り替えられるようにする
- 詳細情報は本の演出だけに依存させず、通常のテキストとして表示する

## 確定内容

- ワークスとインターンシップを1つの本棚にまとめる
- 本棚は最初から表示し、ワークスとインターンシップの区画に分ける
- インターンシップの区画を本棚に設ける
- インターンシップごとに1冊の本として表示する
- 本を選択すると表紙を表示する
- 表紙から「詳細を見る」を選択すると本を開く
- 本のページめくり後に、同じページ内で詳細情報を表示する
- 表紙から戻ると本棚の一覧へ戻る
- インターンシップの内容は会社名、期間、担当内容、経験、学びを中心に整理する
