# インターンシップ デザイン案A

## 案の概要

ワークスと同じ本棚の中に配置する、インターンシップ用の本の区画。
本を選択すると表紙が現れ、ページをめくるように経験を閲覧できる構成。

ワークスとインターンシップを同じ本棚に置き、どちらも本を選択して詳細を読む体験として統一する。

## 全体構成

```text
左側：WORKS                 右側：INTERNSHIP
作品の本                  インターンシップの本
  ↓ 本を選択                 ↓ 本を選択
作品の表紙                 インターンシップの表紙
```

## 本棚内の表示

- ワークスとインターンシップを同じ本棚に配置する
- 本棚の区切りに「INTERNSHIP」などのラベルを表示する
- インターンシップの区画に本を並べる
- ワークスとは表紙の装飾や色を変え、区別できるようにする

## 本を選択した後の表示

- クリックすると本が手前に出て表紙が表示される
- 本は画面中央または右側を中心に表示する
- 本の表紙に会社名やインターンシップ名を表示する
- 本を選択すると、該当するインターンシップの内容を閲覧できる

## 本の閲覧方法

- インターンシップごとに1冊の本として扱う
- 複数の本がある場合は、横並びまたは本棚のように表示する
- 本をクリックすると、ページを開くように詳細情報を表示する
- ページをめくるような動きで、経験の内容を順番に閲覧できるようにする
- 戻る操作では本を閉じ、本棚の一覧へ戻る

## 掲載情報

本の表紙または概要には、以下を表示する候補とする。

- 会社名
- インターンシップ名
- 在籍期間
- 担当内容
- インターンシップで経験したこと
- 詳細ページへのリンク

## インタラクション

- 本にカーソルを合わせると、軽く反応する
- クリックすると本が手前に出て表紙が表示される
- 本をクリックすると、ページを開くように詳細情報を表示する
- ページをめくる操作で内容を切り替える
- 戻る操作で本を閉じ、本棚の一覧へ戻る

## ビジュアルデザイン

- ワークスと同じく、黒背景・白文字を基本とする
- ワークスの引き出しと、インターンシップの扉で形状を明確に分ける
- 本は紙の質感やページの重なりを使い、経験を記録したものとして見せる
- 会社ごとに表紙の色や装飾を変えることを検討する
- 3D表現を使う場合も、会社名や内容が読み取れることを優先する

## アクセシビリティ・代替表示

- 本の演出がなくても、会社名やインターンシップ情報を確認できるようにする
- アニメーション軽減時は、本棚から本の一覧表示へ切り替える
- ページをめくる動きがなくても、ボタンや矢印で内容を切り替えられるようにする
- 詳細情報は本の演出だけに依存させず、通常のテキストとして表示する

## 現時点での確定内容

- ワークスとインターンシップを同じ本棚にまとめる
- 本棚のインターンシップ区画に、本として情報を配置する
- インターンシップごとに本として扱う
- 本を開く、またはページをめくるように詳細を閲覧する
- 作品とインターンシップで表紙のデザインを変え、区別する

## これから決めること

- 本棚の区画と配置
- 本を1冊ずつ表示するか、複数並べるか
- 本の表紙に載せる情報
- ページの構成とページ数
- ページをめくる操作方法
- インターンシップの詳細ページへ移動するかどうか
- 本の質感や3D表現の程度
