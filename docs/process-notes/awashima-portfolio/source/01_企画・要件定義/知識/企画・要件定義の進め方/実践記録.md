# 実践記録

## 2026-10-20

### 行ったこと

- 企画・要件定義を始める前に、何を考えればよいかを整理した。
- 企画と要件定義の違いを確認した。
- 目的、対象ユーザー、課題、価値、機能、MVP、成功指標、制約、仮説を整理する手順をまとめた。
- 実際の企画書を作る前に、ヒアリング形式で順番に確認する方針を決めた。

### 結果

企画・要件定義は、いきなり機能や画面を決める作業ではなく、課題と目的を明確にしてから、必要な機能と制作範囲を具体化する作業だと理解した。

### 次に行うこと

- 作りたいWebアプリの候補を出す。
- 対象ユーザーと利用場面を決める。
- ユーザーの課題を仮説として整理する。
- ヒアリングを進め、企画・要件定義MDを作成する。
