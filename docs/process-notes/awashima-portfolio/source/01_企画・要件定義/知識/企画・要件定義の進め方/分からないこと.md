# 分からないこと

## ユーザーが困っていたこと

企画・要件定義を始めたいが、最初に何を考えればよいのか、どのような方法・順番で整理すればよいのか分からない。

## 今後確認したいこと

- 自分が作るWebアプリの対象ユーザーを誰にするか。
- 対象ユーザーが具体的にどのような課題を持っているか。
- 調査前の仮説と、調査で確認できた事実をどう分けるか。
- 最初の制作でMVPに含める機能をどこまでにするか。
- 成功指標を、今回のWebアプリでどのように設定するか。

## 未確認事項

このメモでは企画・要件定義の一般的な進め方を整理した。実際に作るWebアプリのテーマ、対象ユーザー、課題、機能、調査方法はまだ確定していない。
