# 08 Webアプリ・3D演出実装

## この工程で形にしたもの

企画・調査・Figmaの設計をもとに、背景映像と3Dブックを重ねたポートフォリオを実装した。Codexとサブエージェントを活用し、表示と操作を確認しながら調整した。

| 領域 | 実装した内容 |
|---|---|
| 背景・キャラクター | 一体化したWebP連番をCanvasで描画。入力で映像区間を進め、停止地点ではループを再生 |
| HTML UI | Profile・About Me・History・Contact、ナビゲーション、文字の表示タイミング |
| History | 4カテゴリの本一覧、左右移動、おすすめの本への移動 |
| 3Dブック | 本の選択・開閉、湾曲するページめくり、目次、Demo・GitHubリンク |
| 本の内容 | TypeScriptメタデータとMarkdown。制作原稿と公開スナップショットを分離 |
| 公開 | Next.jsのサイトをVercelで公開 |

## 実装の流れ

1. **映像を試作**：キャラクターだけを切り抜く案から、背景と一緒に動画化して連番に分ける方式へ見直した。
2. **映像と画面を統合**：入力、区間再生、ループと、4画面の文字・ナビを組み合わせた。
3. **本の3D表現を実装**：React Three Fiber・Three.jsで描画し、React SpringとSkinnedMeshで開閉・紙の湾曲を表現した。
4. **操作の競合を整理**：本の閲覧中は背景移動を止める。背景ループは続け、ナビ移動は本を閉じてから行う。
5. **表示を反復調整**：余白、映像のつなぎ、本と文字の登場タイミング、開閉時の揺れ、読み込み演出を見直した。
6. **本制作の仕組みを整備**：作品ごとの原稿・画像・リンクをまとめ、プレビューと明示的な公開反映を用意した。

## 主な技術

- Next.js・React・TypeScript：画面とデータの管理
- WebP・Canvas：背景とキャラクターの連番映像
- Three.js・React Three Fiber：本の3D描画
- SkinnedMesh：紙の湾曲
- React Spring：本の開閉・ページめくり
- Markdown：本の原稿
- Codex：実装支援とサブエージェントの活用

採用理由と見直した案は[技術選定・設計判断](技術選定・設計判断.md)にまとめた。
