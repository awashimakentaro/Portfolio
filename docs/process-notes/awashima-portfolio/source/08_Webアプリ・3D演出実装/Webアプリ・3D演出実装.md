# 08 Webアプリ・3D演出実装

## 目的

確定した設計と検証結果をもとに、動作するWebポートフォリオと、必要な3D・モーション・サウンド演出を実装する。

## 実施する作業

- Webアプリの画面、情報、ナビゲーションを実装する
- 3Dアセットを制作・調整・統合する
- キャラクターの動作、表情、アニメーション、音声・効果音を実装する
- クリック、ホバー、スクロールなどへの反応を実装する
- 音声OFF、アニメーション軽減、3D非対応環境の代替を実装する
- 表示速度、操作性、レスポンシブ、エラー状態を確認する

## 技術候補

Next.js / React / Three.js / React Three Fiber / GSAP / Blender / Spline / 音声・効果音関連技術など。候補であり、実現性、学習コスト、性能、保守性を確認して選定する。

## 成果物

- 動作するWebポートフォリオ
- 3Dアセット
- アニメーション・音声演出
- 実装コード
- 技術選定と技術検証の記録

## 作業フォルダ

- `実装計画.md`：段階1〜4の全体計画と完了条件
- `01_画面設計_Figma/`：Figmaで画面、導線、状態を整理する
- `02_3D制作_技術検証/`：3D制作とWeb表示の小さな検証を行う
- `03_Web統合実装/`：画面と3DをWebへ統合する
- `04_検証_改善/`：操作性、アクセシビリティ、性能を確認する
- `知識/`：工程で学んだことと未解決事項を記録する

## 次工程へ進む目安

主要機能と導線が動作し、演出を利用できない環境でも必要な情報へ到達できる状態。公開前に確認すべきテスト項目が整理されていること。
