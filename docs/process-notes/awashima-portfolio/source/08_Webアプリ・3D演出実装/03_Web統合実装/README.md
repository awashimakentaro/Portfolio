# 段階3：Web統合実装

## 目的

Figmaで確認した画面と導線に、検証済みの3Dキャラクターを統合する。

## 実装の順番

1. HTMLでProfile / About Me / 本棚 / Contactを作る
2. CSSで文字、棚、本、ボタン、余白を整える
3. JavaScriptでナビゲーションと本の状態切り替えを作る
4. 3Dを置くための`character-slot`を用意する
5. 3Dモデルを`character-slot`へ統合する
6. 3Dがない場合の代替表示を残す
7. Reduced Motionとキーボード操作を実装する

## 実装しないもの

- AIチャット
- 会話パネル
- キャラクタークリックによる会話

## 完了条件

- 3Dがなくても主要導線が動く
- 3Dを追加しても文章・本・リンクが使える
- 本の表紙・詳細・戻る操作が分かる
- 3D表示の失敗時にページ全体が壊れない
