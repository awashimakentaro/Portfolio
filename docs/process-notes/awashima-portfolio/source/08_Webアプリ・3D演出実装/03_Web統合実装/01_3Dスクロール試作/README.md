# 3Dスクロール試作

`りぐ.glb` をThree.jsで表示し、Web側のコードだけで待機・横移動・バウンスを合成する技術検証です。

## 起動方法

このフォルダでローカルサーバーを起動します。

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開きます。GLBの読み込みにはローカルサーバーが必要で、`index.html` をダブルクリックして開く方法は使いません。

## 現在の挙動

- 前半：ゆっくり上下に揺れる
- スクロール中：左から右へ移動する
- 後半：バウンドとスカッシュ＆ストレッチ
- `prefers-reduced-motion`：動きを止める
- GLBの読み込み失敗時：代替メッセージを表示する

## 注意

現在のGLBは約35MBあるため、公開前にはテクスチャ圧縮を別途検証します。
