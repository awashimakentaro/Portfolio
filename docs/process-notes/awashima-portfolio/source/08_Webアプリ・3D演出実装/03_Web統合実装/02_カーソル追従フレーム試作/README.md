# カーソル追従フレーム試作

生成した `ezgif-7531659ad6fbd542-png-split.zip` の108枚のPNGを、カーソルの横位置に対応させる試作です。

## 動作

- 画面左端: 1フレーム目
- 画面中央: 54フレーム目前後
- 画面右端: 108フレーム目
- カーソルを動かすと、現在位置に対応するフレームへ滑らかに補間します。
- 左右キー、Home、Endでも確認できます。

## 現時点の注意

抽出画像にはアルファ透過がなく黒背景が含まれていたため、`style.css` の `mix-blend-mode: screen` で黒を背景になじませています。これは見た目上の合成であり、画像自体が透過PNGになったわけではありません。

本番利用では、次のどちらかに進めます。

1. 108枚を背景除去して本当の透過PNGにする
2. 3DモデルをWebGLで表示し、カーソル位置から視線・向きを直接計算する

まずは「カーソル位置でキャラクターの向きが変わる」体験を確認するための実装です。
