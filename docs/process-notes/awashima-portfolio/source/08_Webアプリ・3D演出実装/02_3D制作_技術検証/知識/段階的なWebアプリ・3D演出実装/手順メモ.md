# 手順メモ

## 繰り返し使う進め方

1. 画面の目的と主要導線を文章で確認する
2. Figmaで静的な画面と状態を整理する
3. 3DなしのHTML / CSS / JavaScriptで通常操作を作る
4. キーボード操作、戻る操作、通常リンクを確認する
5. 仮キャラクターや静止画で、演出を入れる位置を確認する
6. 3Dやモーションを一つずつ独立検証する
7. 検証結果を「採用」「縮小」「代替」に分ける
8. 採用した演出だけ本体へ統合する
9. Reduced Motion、3D非対応、素材未読込でも情報が読めることを確認する

## 判断の基準

- 演出がなくても主要情報と主要操作が成立する
- 演出を追加しても、情報へ到達する時間が大きく増えない
- 演出の効果を説明できる
- 読み込み速度、保守性、アクセシビリティに無理がない

## 今回の作業順

`画面構成 → 静的導線 → 仮表現 → 3D技術検証 → 採用判断 → 統合 → アクセシビリティと性能確認`
