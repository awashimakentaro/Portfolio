# 分かったこと

- Meshyは、同一対象を異なる角度から写した1〜4枚の画像を使って、1つの3Dモデルを生成できる。先頭の画像は正面として扱われる。
- Meshyでは画像から作った3DモデルをGLB形式で出力できる。GLBはモデル・質感・骨・アニメーションをまとめてWebへ渡しやすい形式である。
- スクロール連動の演出は、Meshy内で一本の動画として作るものではない。Meshy／Blenderで短い動きの素材を作り、Web側でスクロール位置に応じて位置・カメラ・モーションを切り替える。
- 本棚の扉のように動く部品は、AIで作った棚の見た目と、WebまたはBlenderで作る単純な可動部品を分けると作りやすい。扉は蝶番の位置を支点に回転させる。

## 現在の方針

最初の検証では、Meshyで毛玉キャラの立ち姿を作り、`idle`、`workout`、`bounce` の3モーションを段階的に確認する。キャラ全体の横移動はWeb側の制御にする。
