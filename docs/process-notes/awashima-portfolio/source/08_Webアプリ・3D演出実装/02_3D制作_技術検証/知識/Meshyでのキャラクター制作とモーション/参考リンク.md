# 参考リンク

- [Meshy Workspace](https://www.meshy.ai/ja/workspace) — 画像から3Dモデルを生成する画面。
- [Meshy: Multi-Image to 3D](https://docs.meshy.ai/en/api/multi-image-to-3d) — 複数方向の画像から3Dモデルを作る仕様。最大4枚、先頭画像が正面。
- [Meshy: Animate](https://docs.meshy.ai/en/webapp/guides/animate) — リグとアニメーションの公式ガイド。
- [Three.js: Loading 3D Models](https://threejs.org/manual/en/loading-3d-models.html) — WebでGLB/glTFを読み込む公式ガイド。
- [GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) — スクロール位置に演出を連動させる公式ガイド。
