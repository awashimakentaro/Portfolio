## 2026-11-02：制作方針を整理

- Meshyをキャラクター3D生成の候補として採用した。
- Webで必要な動きは、`idle`、`workout`、`bounce` の3本に分ける方針にした。
- キャラの右移動は、3Dファイルに焼き込まずWeb側で制御する方針にした。
