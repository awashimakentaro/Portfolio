# 手順メモ

## 全体の段階

1. **基準画像を揃える**
   - 正面・右・後ろ・左の4方向画像を、同じ姿勢・比率・背景で用意する。
   - Meshyには4枚を別ファイルとして渡す。1枚目は正面にする。

2. **Meshyでキャラクターの土台を生成する**
   - Workspace の「モデル」→「画像生成モデル」を使う。
   - `マルチビュー` をオンにして4方向画像を入力する。
   - 最初は標準解像度で2〜3案を比較し、採用案だけを高解像度・テクスチャありで出力する。
   - 出力形式はWebに渡しやすい `GLB` を使う。

3. **動かせる状態を確認する**
   - 立ち姿モデルにリグ（動きのための骨組み）を適用できるか確認する。
   - このキャラは非人型のため、人型プリセットがそのまま自然に使えるとは限らない。必要ならBlenderで最低限の専用リグにする。

4. **短いモーションを3本作る**
   - `idle`：立つ・瞬き・小さく揺れる。
   - `workout`：筋トレ表現。腕を追加するならダンベル運動、追加しないならスクワットや踏ん張りにする。
   - `bounce`：ぴょこぴょこ跳ねる。
   - 長い一本の映像ではなく、切り替え可能な短いアニメーションクリップとして扱う。

5. **Webで場面を制御する**
   - キャラ全体の右移動は、MeshyのアニメーションではなくWeb側で行う。
   - スクロール位置に応じて `idle → workout → bounce` を切り替える。
   - スクロールを戻しても自然に戻れるよう、Web側で位置・カメラ・アニメーションを制御する。

6. **小さく統合検証する**
   - まずはGLBをWebで読み込み、Idleだけを再生する。
   - 次に右移動、Workout切替、Bounce切替を一つずつ加える。
   - 最後に容量、読み込み時間、モバイルでの代替表示を確認する。

## 今回作る最小成果物

- 4方向の参照画像
- 立ち姿のGLBモデル 1体
- `idle` / `workout` / `bounce` の3モーション
- スクロールで3場面を切り替える最小Web検証
