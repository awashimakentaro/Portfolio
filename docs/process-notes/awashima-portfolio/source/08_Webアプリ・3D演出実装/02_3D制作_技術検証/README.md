# 段階2：3D制作・技術検証

## 目的

キャラクターを3Dとして制作・表示できるかを、小さな検証から確認する。

## まず比較する候補

- Spline：Web上での見え方と簡単なインタラクションを早く確認する
- Blender：オリジナルモデルを細かく作り、glTF / GLBで書き出す
- Three.js：ブラウザ上でモデルやカメラをJavaScriptから細かく制御する

## 進め方

1. Figmaからキャラクターの役割・サイズ・配置を受け取る
2. 球・箱・簡易人型などの仮モデルで表示テストする
3. SplineまたはBlenderで簡易キャラクターを作る
4. Webへの埋め込み、読み込み、カメラ、背景透過を確認する
5. 容量と表示速度を確認する
6. 「採用」「縮小」「代替」を判断する
7. 必要なら最終モデルを作り込む

## 完了条件

- Web上で簡易3Dを表示できる
- Profile / 本棚 / Contactのどこに置くか確認できる
- 3Dが読み込めない場合の代替表示を決めている
- 本体統合に進む技術と形式を決めている
