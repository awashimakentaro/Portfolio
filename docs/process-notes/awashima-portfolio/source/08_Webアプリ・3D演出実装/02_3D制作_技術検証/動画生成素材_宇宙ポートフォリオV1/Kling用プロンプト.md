# Kling用プロンプト：宇宙ポートフォリオ V1

## 参照画像

- `01_hero_開始.png`：Heroの開始状態
- `02_workout_開始_v2.png`：筋トレ場面の開始状態（月を右側に配置）
- `03_warp後_背景.png`：ワープ後の背景
- `04_contact_UFO_v2.png`：Contact場面の開始状態（目を整え、UFOに乗せた版）
- 元のFigma画像：全体のデザイン・キャラクターの参考。画面内の文字やUIは動画に生成しない

画像は動画生成AIにキャラクター・背景・構図の参照として添付する。開始画像と終了画像を指定できるモードでは、各クリップの対応画像を開始・終了に設定する。

## 共通指示

```text
添付画像の白い毛玉のような目玉キャラクターと、モノクロームの宇宙ポートフォリオの世界観を参照する。映像全体で同じキャラクターの目、毛束の形、脚、靴、色、質感を保つ。カメラは正面から固定し、ズーム、パン、回転、手ブレ、画角変更をしない。背景は映像に含めたままにする。画面内の文字、字幕、ロゴ、UIを生成しない。急な形状変化、別キャラクター化、余分な手足、背景の点滅を避ける。動きは滑らかで、控えめで、かわいらしい。
```

## クリップA：Heroの待機

添付：`01_hero_開始.png`。短いループとして作る。

```text
正面固定カメラ。巨大な月と静かな宇宙、反射する月面を背景に、キャラクターが画面中央で立っている。キャラクターはその場でごく小さく上下に揺れ、毛先がわずかに風になびく。大きな移動やポーズ変更はしない。月、星、地形はほぼ静止し、光も安定させる。最後は開始画像と同じ位置・大きさ・姿勢に戻り、自然につながる短い待機ループにする。
```

## クリップB：Heroから筋トレ位置へ

開始：`01_hero_開始.png`／終了：`02_workout_開始_v2.png`。

```text
固定カメラのまま、開始画像の中央に立つキャラクターが、ゆっくり右側へ移動する。移動中、体を少し右下へ傾け、自然に筋トレの準備姿勢へ移る。終了画像のように画面右側で止まり、両手にダンベルを持った開始ポーズになる。キャラクターの大きさは大きく変えない。月と宇宙の背景は同じ場所に保ち、移動に合わせてごくわずかな奥行き感だけを出す。カメラは動かさない。最後は終了画像の位置・姿勢に合わせて静止する。
```

## クリップC：筋トレ開始からワープ

開始：筋トレ姿勢の映像または`02_workout_開始_v2.png`／終了：`03_warp後_背景.png`。

```text
キャラクターは画面右側の筋トレ開始ポーズから、ごく短くダンベルを一度だけ持ち上げる。その直後、白い光の輪と控えめな星粒がキャラクターの周囲に集まり、キャラクターだけが小さくポンとワープして消える。光はすぐ弱まり、終了画像の静かな月面風の背景へ自然につながる。背景とカメラは固定。爆発、煙、激しいフラッシュ、画面全体の白飛びは起こさない。最後はキャラクターのいない背景で止める。
```

## クリップD：Contactで再登場

開始：`03_warp後_背景.png`／終了：`04_contact_UFO_v2.png`。

```text
固定カメラ。静かな月面風の背景の右側に、小さな銀色の光が集まり、キャラクターが「ポン」とかわいく現れる。キャラクターは終了画像と同じ右側の位置に立ち、少しだけこちらを向いて落ち着く。光の輪と粒子は控えめにしてすぐ消す。背景は月面と宇宙のまま安定させる。文字、吹き出し、UIは生成しない。最後は終了画像の構図に合わせる。
```

## 作成・実装の順番

1. まずクリップBを開始・終了画像付きで短く生成し、キャラクターと背景がつながるか確認する。
2. 次にC、Dを個別に生成する。必要ならAは待機用ループとして別に作る。
3. Webでは各動画の再生位置をスクロール量に対応させる。動画の背景込みで表示し、全身の切り抜きは行わない。
4. カーソル追従は動画に任せず、目の部分だけ別レイヤーで実装する。動画内の目は正面を保つ。
5. クリップの接続点で背景・床の位置がずれる場合は、生成し直す前にWeb側で短いクロスフェードを試す。

## 注意

生成画像は動画生成AIに渡すための構図・雰囲気の参照素材。元Figmaと完全一致する完成アセットではない。特にキャラクターの細部は動画生成で変化する可能性があるため、まず短いクリップで一場面ずつ確認する。
