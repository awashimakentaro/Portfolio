# 段階4：検証・改善

## 目的

3D演出を含めた状態で、情報の読みやすさ、操作性、表示速度、代替状態を確認する。

## 確認項目

- ProfileからContactまで迷わず移動できるか
- 本棚 → 表紙 → 詳細 → 本棚へ戻れるか
- 3Dがなくても情報を読めるか
- `prefers-reduced-motion`で動きを減らせるか
- キーボードで本とボタンを操作できるか
- 3D読み込み中・失敗時もページが使えるか
- 横スクロールや過度な読み込みが発生しないか

## 完了条件

問題を「必須修正」「改善候補」「後回し」に分類し、公開前に対応すべきものが明確になっている。
