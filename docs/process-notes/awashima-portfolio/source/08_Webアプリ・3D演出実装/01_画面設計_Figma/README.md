# 段階1：画面設計（Figma）

## 目的

3Dが表示されなくても成立する、ポートフォリオの画面構成と操作導線をFigmaで確認する。

## 作るもの

- Profile / About Me / 本棚 / Contact
- 固定グローバルナビゲーション
- WorksとInternshipの本棚区画
- 本の通常状態、ホバー・フォーカス状態、選択状態
- 表紙、詳細、戻る操作の状態
- キャラクターを置くためのサイズ・位置・役割

## 進め方

1. 1440px幅を基準に主要セクションを作る
2. 文字と通常ボタンだけで情報が読める状態にする
3. 本棚 → 表紙 → 詳細 → 本棚の接続を作る
4. キャラクターは仮画像またはシルエットで置く
5. キャラクターなしの状態でも画面が成立するか確認する
6. 3D制作へ渡すため、キャラクターの表示領域・視線・配置を記録する

## 完了条件

- ProfileからContactまでの導線を説明できる
- 作品とインターンシップの情報構造が区別できる
- 3Dやアニメーションなしでも主要操作が分かる
- 3Dキャラクターに必要な画面サイズと役割が決まっている
