# 学ぶ理由

## 今回知りたいこと

ユーザー調査で得た気づきを、ポートフォリオサイトの具体的な機能・掲載情報・ページ構成へ落とし込む方法を理解する。

## この工程で解決したい疑問

要件定義をユーザー調査によって磨いたあと、機能・情報設計では具体的に何を決め、何を成果物として残せばよいのか。

## 学ぶ目的

- 調査結果をそのまま機能にせず、ユーザーの目的や課題から必要なものを整理できるようにする
- ポートフォリオに載せる情報と、載せなくてよい情報を判断できるようにする
- サイトマップや優先順位を作り、次のユーザーフロー・ワイヤーフレームへ迷わず進めるようにする

## 対象

ポートフォリオサイトの「機能・情報設計」工程。対象サイトの技術や使用ツールは、このメモでは前提にしない。
