# 分からないこと

## 未確認の事項

- このポートフォリオの最優先ユーザーが、採用担当者・クライアント・同業者のどれなのかは未確認
- ユーザー調査で実際にどの発言が得られたか、調査結果の原文はこのメモでは未確認
- 問い合わせを最終成果とするのか、作品理解や採用判断を最終成果とするのかは未確定
- 作品数や作品ごとの情報量によって、独立ページにするか1ページ内のセクションにするかは未決定
- 絞り込み、検索、アニメーションなどの追加機能が本当に必要かは、ユーザー調査と制作コストを見て判断する必要がある

## 次に確認すること

1. ユーザー調査の記録から、ユーザーの目的・困りごと・必要情報を抜き出す
2. 最優先ユーザーと、サイトで達成してほしい行動を1つに絞る
3. 機能一覧・掲載情報一覧に、調査済みか仮説かを記入する
4. サイトマップ案を作り、ページ数と情報の重複を確認する
5. ユーザーフローへ進み、主要導線を確認する

## 注意

このメモのポートフォリオ例は一般的な例であり、現在の制作物に必要な機能を確定したものではない。
