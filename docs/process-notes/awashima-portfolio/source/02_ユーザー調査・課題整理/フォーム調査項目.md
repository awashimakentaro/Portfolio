# ポートフォリオの閲覧・評価に関する調査

## 回答フォーム

[Googleフォームを開く](https://docs.google.com/forms/d/e/1FAIpQLSeWeAtOPDMrvX_R9cBa0XgEsBEGRFfvwBTFwi6FaisbwCChzA/viewform)

## 調査目的

awashima-worldのUI/UXポートフォリオを、採用や協業の場面でより役立つ内容に改善するための調査。

- 所要時間：5〜10分
- 回答：任意
- 回答の用途：ポートフォリオの改善および調査結果の整理
- 実際の採用経験に基づく回答と、仮定・一般的な意見を区別して回答してもらう

## 1. 回答者の属性・経験

### 1-1. あなたの主な職種・立場を教えてください。

- 回答形式：ラジオボタン
- 選択肢：エンジニア／起業家・経営者／デザイナー採用に関わる立場／その他

### 1-2. UI/UXデザインまたは採用に関して、当てはまる経験を教えてください。

- 回答形式：チェックボックス
- 選択肢：UI/UXデザインの実務経験／デザイナー採用の経験／候補者のポートフォリオを評価した経験／いずれも経験なし

### 1-3. 候補者のポートフォリオを閲覧する頻度を教えてください。

- 回答形式：ラジオボタン
- 選択肢：ほとんどない／年に数回／月に1〜2回／月に3回以上／週に1回以上

## 2. 閲覧行動

ポートフォリオを閲覧するときの行動や、情報を探す順番について調査する。

### 2-1. ポートフォリオを開いて最初に確認する情報を教えてください。

- 回答形式：チェックボックス
- 選択肢：プロフィール・経歴／代表的な制作物・プロジェクト／スキル・使用ツール／成果や実績／連絡先・問い合わせ方法／作品一覧／制作期間／使用技術／その他

### 2-2. ポートフォリオを閲覧する際に、情報が見つからず困った経験や離脱した理由があれば教えてください。

- 回答形式：段落・任意

### 2-3. ポートフォリオで、実務能力を判断するために必要だと思う情報を教えてください。

- 回答形式：段落・任意

### 2-4. ポートフォリオを評価するとき、次の項目をどの程度重視しますか。

- 回答形式：5段階選択式グリッド
- 行：情報の見やすさ／制作背景・課題設定／成果・効果／プロセス・改善内容／実績の具体性
- 列：1 まったく重視しない／2／3／4／5 とても重視する

## 3. 評価基準と改善課題

### 3-1. ポートフォリオに不足していると感じる情報があれば教えてください。

- 回答形式：段落・任意

### 3-2. 実際の採用や協業の判断で、ポートフォリオを見たときに残る不安や疑問を教えてください。

- 回答形式：段落・任意

### 3-3. ポートフォリオの内容や見せ方について、改善するとより評価しやすくなる点を教えてください。

- 回答形式：段落・任意

## 4. キャラクター演出とAIチャット

### 4-1. キャラクター演出があるポートフォリオを見たときの印象を教えてください。

- 回答形式：ラジオボタン
- 選択肢：親しみやすく、印象に残る／デザインの意図が伝わりやすい／特に気にならない

### 4-2. AIチャットがある場合、どのような情報を知りたいですか。

- 回答形式：段落・任意

### 4-3. AIチャットがポートフォリオ評価に与える影響について、率直な意見を教えてください。

- 回答形式：段落・任意

## 5. 既存ポートフォリオサイトを見た感想

対象サイト：[https://www.awashima.dev/](https://www.awashima.dev/)

### 5-1. 既存ポートフォリオサイト（awashima.dev）を閲覧しましたか？

- 回答形式：ラジオボタン・必須
- 選択肢：最後まで閲覧した／一部を閲覧した／トップページのみ閲覧した／まだ閲覧していない

### 5-2. サイトを開いて最初に受けた印象に近いものを教えてください。

- 回答形式：段落・任意

### 5-3. 既存サイトを見て、特に良いと感じた点を教えてください。

- 回答形式：段落・任意

### 5-4. 既存サイトを見て、改善したほうがよい点や分かりにくかった点を具体的に教えてください。

- 回答形式：段落・任意

### 5-5. サイト全体について、率直な感想や提案があれば教えてください。

- 回答形式：段落・任意

### 5-6. サイトを閲覧して、改善するとよいと感じた点を教えてください。（複数選択可）

- 回答形式：チェックボックス・任意
- 選択肢：
  - 最初の画面で何をしている人か分かりにくい
  - 作品・プロジェクトの見つけやすさ
  - 制作物の説明や成果が不足している
  - 文章の読みやすさ
  - ナビゲーションの分かりやすさ
  - キャラクター・ビジュアル表現
  - スマートフォンでの見やすさ
  - 問い合わせ・連絡方法の分かりやすさ
  - 特に改善点はない

## 調査結果から確認したいこと

1. 回答者が最初に確認する情報は何か
2. ポートフォリオの評価に必要な情報は何か
3. 採用・協業の判断時に不安や疑問になる点は何か
4. 現在のサイトで評価されている点と改善すべき点は何か
5. キャラクター演出やAIチャットが評価に与える影響は何か
