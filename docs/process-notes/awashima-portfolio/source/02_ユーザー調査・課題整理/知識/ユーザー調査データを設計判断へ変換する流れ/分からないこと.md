# 分からないこと

- 実際の採用担当者だけを対象にした場合も同じ傾向になるか
- 仮想ペルソナによる合成回答を、実回答とどのように分けて集計するか
- 3件の回答で、どの程度まで課題を一般化してよいか
- 「分かりにくい」原因が、情報不足なのか、レイアウトなのか、文章表現なのか
- 自由記述のテーマ分類に、別の解釈が入り込んでいないか
- 課題ごとの改善コストを、どの基準で見積もるか
- 改善後に何を指標にして効果を測るか
- 回答者が最初の画面で実際にどこを見ているかを確認する方法
- 作品の成果が分かりやすくなったかを、どの質問で再検証するか

## 次回確認したいこと

1. 回答者を実際の採用担当者・現場デザイナー・一般閲覧者に分ける
2. 合成回答は「参考ペルソナ」として別集計にする
3. 同じ課題について、自由記述で具体的な場面を聞く
4. 改善案をプロトタイプにして、タスク形式で確認する
5. 回答数と属性が増えた段階で、今回の仮説を再評価する
