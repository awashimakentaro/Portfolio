# 実践記録

## 2026-10-20

### 実施したこと

- 要件定義の次の工程として、ユーザー調査・課題整理の目的を整理した
- 調査対象を知り合いのエンジニア・起業家とし、デザイナー視点とエンジニア視点の両方から回答してもらう方針を決めた
- Googleフォームによるアンケート調査の方針を決めた
- 回答を分析し、課題を優先順位付けして再定義する流れを整理した
- フロー図のスクリーンショットを保存した

### 次に行うこと

- Googleフォームの質問を作成する
- 回答者に想定してもらう立場を質問文で明確にする
- 回答を「事実」「課題の仮説」「対応案」に分けて記録する
- 課題の優先順位を決める
- 調査結果を反映した情報設計・ユーザーフローを作成する
