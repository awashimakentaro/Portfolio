# 分からないこと

- 実際の採用担当者は、最初にどの情報を確認するのか
- ポートフォリオの閲覧に使える時間はどの程度なのか
- キャラクターやアニメーションが、採用判断にどのような影響を与えるのか
- 制作過程のうち、どこまで見せると評価につながるのか
- デザイナー視点とエンジニア視点で、必要な情報にどの程度の違いがあるのか
- Googleフォームの回答数が少ない場合、どの意見を一般化してよいのか
- 調査結果をもとに、現在の要件のどこを変更するべきか

## 未確認事項

今回の調査だけでは採用担当者全体の意見は確認できない。必要に応じて、公開されているポートフォリオ事例や求人情報、実際の採用経験者の意見も追加で確認する。
