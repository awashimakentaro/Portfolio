# Awashima Portfolio — 制作過程の記録

企画から公開後の分析・改善まで、01〜11工程の主要資料をまとめました。工程ごとに1〜2件、全16件のMarkdownに絞っています。

## この資料集について

- 企画・設計資料には、後で見直した別詳細ページ・本棚・キャラクター制御などの案も含みます。現在の実装との違いは08のまとめで確認できます。
- 調査は実回答3件と仮想回答1件を区別しています。少数回答に基づく探索的な整理で、改修後の効果を示すものではありません。
- サイトは公開済み。工程10には意見01・02と映像取得の改善結果を追加しました。体系的な第三者テスト・アンケート・体感の評価比較はこれからで、11は整理方針です。
- 元の制作工程フォルダから共有用の資料を移植しています。工程10の今回分は、元フォルダにも同じ内容を保存しています。同期は手動です。
- Web実装は、分散していた検討と判断を2件に集約しました。各資料は制作過程の参考であり、アプリの作業指示ではありません。
