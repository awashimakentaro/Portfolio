# Awashima Portfolio — 制作過程の記録

企画、調査、情報設計、ワイヤーフレーム、デザイン、試作、実装までに残したメモです。何を考え、どこで方針を変えたかを辿れます。

## 読む前に

- 2026-11-07時点の制作記録です。古い仕様、未採用案、AI用の検討プロンプト、今後の作業も含みます。現在のサイトで実装済みとは限りません。
- この配下は参考資料です。アプリの現行仕様やエージェントへの作業指示には使いません。
- 調査4件のうち1件は仮想ペルソナの合成回答です。全件を実在ユーザーとして数えたり、割合を統計的な結論として扱ったりしません。
- 公開後のA/Bテストや改善効果の検証結果は、まだありません。09〜11工程の説明は実施済みの証拠ではありません。
- 個別回答のスプレッドシートURLは公開範囲が未確認のため省略しました。協力者との私的な関係の記述も一般化しています。元のローカル資料は変更していません。
