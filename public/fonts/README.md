# Portfolio text font

Zen Kaku Gothic New Regular, SIL Open Font License 1.1.

Source: https://github.com/google/fonts/tree/main/ofl/zenkakugothicnew
Original: ZenKakuGothicNew-Regular.ttf (Google Fonts repository).
Converted to WOFF without subsetting with fontTools. The full character set is retained for future manuscripts. See OFL-ZenKakuGothicNew.txt. The font is served locally; no Google Fonts request is made at runtime.
