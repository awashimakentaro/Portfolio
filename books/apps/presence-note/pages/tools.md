## ソフトウェア

- Python — 受信・画像処理・印刷の連携
- ntfy / SSE — 画像付きメッセージの受信
- Pillow — 印刷前の画像処理
- CUPS / AirPrint・IPP — 印刷制御
- systemd — 常駐と起動管理

## ハードウェア

- Raspberry Pi 4 — 画像の受信と処理
- Canon SELPHY CP1500 — 写真の印刷
- Wi-Fi — ネットワーク接続
